# docs/ —— 知识库语料

仓库自带一份示例语料（战略规划方法论 + 行业报告），可以直接跑通全流程。
它们都是公开资料，可以自由替换成你自己的文档。

## 目录约定：一个子目录 = 一个可筛选的「文档范围」

```
docs/
├── 战略规划方法论/     ← 15 份（md / html / docx / pptx）
└── 行业报告/          ← 3 份 PDF
```

支持格式：`.txt` `.md` `.html` `.pdf` `.docx` `.pptx`
（`.xlsx` 不支持，把内容贴进 txt/md）

## 换成你自己的资料

```powershell
python build_index.py     # 会打印「共 N 块」
```

之后就能在控制台的「📁 文档范围」里按文件夹筛选检索。

> ⚠️ 换语料会让 `VERSION` 自动 +1（内容指纹变了），旧数据集与新库不可比 ——
> 这是有意为之：避免把两个不同语料的分数混在一起比较。
