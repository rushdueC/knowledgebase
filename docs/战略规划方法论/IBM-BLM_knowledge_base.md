## 1.0 BLM概述

### BLM-001 IBM业务领先模型(BLM)定义

**小节：** 1.0  
**关键概念：** BLM、战略制定与执行联接、系统思考、资源调配、执行跟踪

Business Leadership Model（BLM）是一个IBM中高层用于战略制定与执行联接的方法与平台。它从市场分析、战略意图、创新焦点、业务设计、关键任务、正式组织、人才、氛围与文化以及领导力与价值观等各个方面帮助管理层在企业战略制定与执行的过程中进行系统的思考、务实的分析、有效的资源调配及执行跟踪。

BLM使IBM成功的四要素——战略、执行、价值观与领导力之间相一致，从而为IBM带来了多方面的业务价值：共同的目标、同一种语言、执行的跟踪、最基本的方法、逻辑的力量、自上而下实施。

### BLM-002 BLM模型结构与要素

**小节：** 1.0  
**关键概念：** 领导力、价值观、战略、执行、市场结果、差距

BLM模型包含以下核心要素：

| 维度 | 要素 | 说明 |
|------|------|------|
| **领导力** | — | 根本，高层管理者需具备的基本能力和必备能力 |
| **价值观** | — | 基础，决策与行动的基本准则 |
| **战略** | 市场洞察 | 了解客户需求、竞争者动向、技术发展和市场经济状况 |
| | 战略意图 | 组织机构的方向和最终目标 |
| | 创新焦点 | 与市场同步的探索与试验 |
| | 业务设计 | 利用内部能力和战略控制点探索可替代的业务设计 |
| **执行** | 关键任务 | 满足业务设计和价值主张要求的必须行动 |
| | 相互依赖关系 | 组织间的相互依赖关系是有效业务设计的基础 |
| | 正式组织 | 组织结构、管理和考核标准 |
| | 人才 | 重要岗位人员需具备相应能力 |
| | 氛围与文化 | 创造好的工作环境以激励员工 |
| **差距** | 业绩差距 | 现有经营结果和期望值之间差距的量化陈述 |
| | 机会差距 | 现有经营结果和新的业务设计所能带来结果的差距评估 |
| **市场结果** | — | 战略与执行联接的产出 |

战略是由不满意激发的，而不满意是对现状和期望之间差距的一种感知。

## 2.0 领导力与价值观

### BLM-003 领导力是根本

**小节：** 2.0  
**关键概念：** 领导力、战略设计、执行计划、高层管理者

BLM业务领先模型是创造快速和持续适应不断改变的业务的核心，它的运用是IBM的高层管理者需要具备的基本能力和必备能力，通过积极的实践得以发展。

IBM的高管层的领导力培养是通过领导他们的高层团队进行战略问题和机会的勘查与设计以及项目的执行来推动变革。战略设计与执行计划是高管层每年都要亲自领导的，在获得对外部市场的持续洞察、识别新的机会、开发业务设计、确保这些设计是切实可行的过程中发挥关键作用。

---

### BLM-004 价值观是基础

**小节：** 2.0  
**关键概念：** 价值观、决策准则、日常执行

IBM价值观：成就客户、创新为要、诚信负责。

作为业务的主要战略家的总经理，要确保IBM价值观反映在公司的战略上，各级领导者要确保IBM价值观是日常执行中的一部分。IBM价值观是我们决策与行动的基本准则。

## 3.0 差距分析

### BLM-005 业绩差距与机会差距

**小节：** 3.0  
**关键概念：** 业绩差距、机会差距、业务设计、高效执行

| 差距类型 | 定义 | 填补方式 |
|----------|------|----------|
| **业绩差距** | 现有经营结果和期望值之间差距的一种量化的陈述 | 常常可以通过高效的执行填补，不需要改变业务设计 |
| **机会差距** | 现有经营结果和新的业务设计所能带来的经营结果之间差距的一种量化的评估 | 需要有新的业务设计 |

战略是由不满意激发的，而不满意是对现状和期望业绩之间差距的一种感知。

---

### BLM-006 差距分析示例

**小节：** 3.0  
**关键概念：** 业绩差距示例、机会差距示例、负责人

**业绩差距示例：** 过去的五年业务急剧增长，在此期间产品质量有所下降。引进六西格玛的尝试失败了，在过去12个月里失去了5%的市场份额。每一个百分点代表着约5亿美元收入损失。目标是在未来24个月收复损失掉的市场份额。

**机会差距示例：** 研发小组开发出了新的技术平台，在国内业界是一个潜在的颠覆性技术。第一先行者的机会在12-18个月内，如果在未来6个月能推出此技术。但目前的产品开发周期需要18-24个月，要取得成功，必须把这个周期缩短到6个月。

---

### BLM-007 找出差距的流程

**小节：** 3.0  
**关键概念：** 列出问题、关键差距、负责人

找出差距的三个步骤：

1. **列出目前所有的问题** — 全面梳理现存差距
2. **选出关键的差距** — 考虑对成本、战略层面的影响
3. **决定负责人** — 明确差距缩小/关闭的责任人

差距描述的要求：
- 陈述的是业务结果，如收入、利润/贡献和市场份额
- 形成差距的主要原因
- 有时间的约束和可量化
- 有一个明确的负责人，承担缩小差距的责任

## 4.0 战略——市场洞察

### BLM-008 市场洞察概述

**小节：** 4.0  
**关键概念：** 市场洞察、客户需求、竞争者动向、技术发展、市场经济状况

市场洞察力：了解客户需求、竞争者的动向、技术的发展和市场经济状况以找到机遇和风险。

目标：解释市场上正在发生什么以及这些改变对公司来说意味着什么。

市场洞察包含三个维度：
- **宏观分析**：宏观环境对行业的影响
- **竞争动向**：竞争对手的战略和策略
- **客户分析**：客户需求、偏好和购买行为

市场洞察力的缺失会对业务设计产生负面影响，因为所采用的支撑信息和假设可能是有瑕疵的或错误的。

---

### BLM-009 市场洞察：环境驱动力

**小节：** 4.0  
**关键概念：** 环境驱动力、技术与服务、客户、竞争对手、人口统计、法律法规

对客户、竞争对手的影响分析框架：

| 环境驱动力 | 关注内容 |
|------------|----------|
| **技术与服务** | 在技术与服务领域里的趋势和变化 |
| **客户** | 需求与当务之急的挑战，为什么客户选择你的产品与服务 |
| **竞争对手** | 竞争市场上正在发生什么变化，谁是主要竞争对手 |
| **人口统计数据** | 将会对业界产生影响的生活方式、时尚以及文化变化趋势 |
| **法律、政治** | 政治、政府法律法规的变化 |

同时需要关注客户的客户和竞争对手的分类分析。

---

### BLM-010 市场定位框架

**小节：** 4.0  
**关键概念：** 市场吸引力、竞争定位、CAGR、市场参与者、市场领先者

基于市场增长率（CAGR）和竞争定位（Sales/Sales Margin）两个维度，将市场地位分为四类：

| 竞争定位 | 高增长 | 低增长 |
|----------|--------|--------|
| **高** | 保持/投入 — 高增长市场领先者 | 收获 — 低增长市场领先者 |
| **低** | 再评估/投入 — 高增长市场参与者 | 放弃 — 低增长市场参与者 |

## 5.0 战略——战略意图

### BLM-011 战略意图三要素

**小节：** 5.0  
**关键概念：** 愿景、战略目标、近期目标

战略意图：组织机构的方向和最终目标，与公司的战略重点相一致，体现竞争优势。

| 要素 | 定义 | 内容 |
|------|------|------|
| **愿景** | 可持续的、占优势的业务领先地位 | 纲领意义，感情契约，现实但有挑战性 |
| **战略目标** | 有效的、合理的、灵活的运营模式 | 产品、服务、市场、客户、技术及时机 |
| **近期目标** | 业绩可衡量的指标 | 利润、成长率、市场份额、客户满意度及新产品 |

## 6.0 战略——创新焦点

### BLM-012 创新焦点三要素

**小节：** 6.0  
**关键概念：** 未来业务组合、创新模式、资源利用

创新焦点：进行与市场同步的探索与试验。从广泛的资源中过滤想法，通过试点和深入市场的实验探索新想法，谨慎地进行投资和处理资源，以应对行业的变化。

三个要素：
1. **未来业务组合** — 管理三个成长地平线的业务组合
2. **创新模式** — 产品/服务/市场创新、业务模式创新、运营创新
3. **资源利用** — 谨慎投资，有效处理资源

---

### BLM-013 麦肯锡增长业绩矩阵

**小节：** 6.0  
**关键概念：** 增长明星、徒劳无功、业绩至上、面临危机、增长引擎

麦肯锡对美国最大100家公司跨越2个经济周期的跟踪调查，以收入增长和股东总体回报为两个维度，将企业分为四类：

| 类型 | 特征 |
|------|------|
| **增长明星** | 高收入增长、高股东回报 |
| **徒劳无功** | 高收入增长、低股东回报 |
| **业绩至上** | 低收入增长、高股东回报 |
| **面临危机** | 低收入增长、低股东回报 |

增长引擎的驱动因素：
- **业务组合增长** — "前人栽树，后人乘凉"，很少是增长的驱动因素
- **市场份额增加** — 比想象的更重要
- **并购** — 很少是增长的驱动因素

### BLM-014 三个成长的地平线

**小节：** 6.0  
**关键概念：** H1核心业务、H2成长业务、H3新兴机会、Compete to Win、Change the Game

| 地平线 | 定义 | 管理重点 | 关键指标 |
|--------|------|----------|----------|
| **H1 — 核心业务** (Stay in the Game) | 成熟业务，收入与利润的主要来源 | 近期利润表现与现金流 | 利润、ROIC、生产效率 |
| **H2 — 成长业务** (Compete to Win) | 增长业务，市场增长和扩张机会的来源 | 收入增长和投资回报 | 收入增长、新客户获取、市场份额增长 |
| **H3 — 新兴机会** (Change the Game) | 产品/业务创新的组合，未来长期增长的机会点 | 回报多少和成功的可能性 | 项目里程碑、机会点数量和回报评估 |

### BLM-015 企业创新三种典型模式

**小节：** 6.0  
**关键概念：** 产品/服务/市场创新、业务模式创新、运营创新

| 创新模式 | 应用领域 | 关注点 |
|----------|----------|--------|
| **产品/服务/市场创新** | 聚焦客户和进入市场领域 | 发展和发行创新产品和服务、进入新市场、寻找新客户、推行新渠道和交付路径。**关注成长** |
| **业务模式创新** | 重建和企业扩展 | 发展业务运营的新方式、建立伙伴关系快速响应市场、提升业务灵活性 |
| **运营创新** | 改善核心职能领域 | 发展最佳成本结构、优化流程改进生产力、核心职能再造以提高效率。**关注成本** |

创新领域涵盖六个层面：产品创新、服务创新、业务流程创新、业务模式创新、文化和管理创新、政策和社区创新。

## 7.0 战略——业务设计

### BLM-016 业务设计概述

**小节：** 7.0  
**关键概念：** 业务设计、客户选择、价值主张、价值获取、活动范围、持续价值、风险管理

业务设计应以对外部的深入理解为基础，着眼于更好地利用内部能力和持续改进与变革，探索可替代的业务设计。业务设计是战略制定的落脚点，也是迈向执行的关键。

业务设计六要素：

| 要素 | 核心问题 |
|------|----------|
| **客户选择** | 谁是你的客户，谁不是？如何确定优先级？ |
| **价值主张** | 客户需求、独特性、有影响力 |
| **价值获取** | 如何赚钱？靠什么吸引客户并获取利润？ |
| **活动范围** | 经营活动中的角色和范围，哪些外包外购？ |
| **持续价值增值** | 如何保护利润？战略控制点是什么？ |
| **风险管理** | 不确定性识别、潜在风险评估与管理 |

---

### BLM-017 业务设计：客户选择与价值主张

**小节：** 7.0  
**关键概念：** 客户选择标准、优先级、客户需求、独特性、$APPEALS

**客户选择：** 选择客户的标准，如何确定优先级——谁是你的客户，谁不是。在该细分市场下，客户有哪些特定的需求。关注快速增长市场和CSR（企业社会责任）。

**价值主张：**
- **客户需求** — 我们提供的产品和服务是否以客户的最终需求为导向
- **独特性** — 客户是否真正认可我们的产品和服务
- **有影响力** — 是否能帮助客户实现增值和收益

可使用$APPEALS框架进行价值主张分析。

---

### BLM-018 业务设计：价值获取与活动范围

**小节：** 7.0  
**关键概念：** 盈利模式、利润区、外包外购、合作伙伴协作

**价值获取：** 如何赚钱？我们依靠什么吸引客户并获取利润？有其他的盈利模式吗？（可参考《发现利润区》）

**活动范围：** 经营活动中的角色和范围。哪些外包、外购？与合作伙伴的协作。公司致力于哪些业务活动（What），如何联结各业务活动（How），如何选择最合适的业务活动地点（Where）。

---

### BLM-019 业务设计：持续价值增值与风险管理

**小节：** 7.0  
**关键概念：** 战略控制点、价值链地位、不确定性、潜在风险

**持续价值增值：**
- 客户需求的转移趋势
- 价值链中的地位
- 如何保护利润 — 快速响应、有效控制成本、专利等
- 战略控制点

**业务风险管理：**
- 不确定性识别
- 潜在风险：市场、对手、技术
- 全面视角 — 外部和内部

---

### BLM-020 业务设计案例：眼镜行业

**小节：** 7.0  
**关键概念：** 差异化业务设计、客户选择、价值主张、活动范围

眼镜行业三种不同业务设计对比：

| 维度 | 低成本策略 | 高质量追逐时尚 | 高品质时尚健康 |
|------|-----------|---------------|---------------|
| **客户选择** | 注重"成本"的购买者 | 注重"时尚"的购买者 | 注重"品质"的购买者 |
| **价值主张** | "低成本"策略 | "高质量、追逐时尚"的代言 | "高品质、时尚和健康"的选择 |
| **品牌** | 沃尔玛连锁卖场 | 品牌眼镜店（日本） | Luxottica（意大利） |
| **设计** | 公司内部 | 公司内部 | 意大利—世界时尚窗口 |
| **生产** | 公司内部 | 韩国/中国生产 | 公司内部 |
| **零售** | 沃尔玛遍布世界 | 品牌眼镜店 | Sunglass Huts和Lenscrafters |

### BLM-021 业务设计是迈向执行的关键

**小节：** 7.0  
**关键概念：** 现有业务设计、期望业务设计、能力要求、战略意图、创新焦点

业务设计是从战略到执行的关键转折点。需要对比现有业务设计与期望业务设计：

**现有业务设计 vs 期望业务设计**（六个要素逐一对比）：
- 客户选择 → 谁是你的客户？
- 价值主张 → 怎样实现竞争优势（差异）？
- 价值获取 → 怎样获利？有其他盈利模式吗？
- 活动范围 → 经营活动中的角色和范围
- 价值增值 → 怎样建立持续利润增长？在价值链中的角色
- 风险管理 → 有哪些潜在风险？怎样管理？

**关键检验问题：**
- 对市场的洞察力：这个业务设计所依赖的客户角度和经济上的假设是什么？
- 战略意图：这个业务设计是否提升了公司的战略重点？
- 创新焦点：新的业务设计能否抓住新的价值来源？这种价值来源是可持续的吗？
- 对能力的要求：我们是否建立在现有能力上？能否获得所要的新能力？

---

## 8.0 执行——关键任务与依赖关系

### BLM-022 关键任务

**小节：** 8.0  
**关键概念：** 关键任务、战略举措、依赖关系、年度跟踪

关键任务：满足业务设计和它的价值主张的要求所必须的行动。

关键任务的特征：
- 支持业务设计、尤其是价值主张的实现
- 主要是指持续性的战略举措（ongoing activity），包括业务增长举措和能力建设举措
- 可从以下方面思考：客户管理、产品营销、产品开发、交付、平台、服务、风险管理和能力建设
- 将重要运营流程的设计与落实包括在内
- 是执行的其他部分的基础
- 年度性的、可按季度跟踪衡量
- 需识别出关键任务之间的相互依赖关系（资源、设施等）

---

### BLM-023 相互依赖关系

**小节：** 8.0  
**关键概念：** 内部依赖、外部依赖、供应商、外包伙伴、客户与渠道、信任、同盟

**内部互相依赖关系**包括：
- 供应商（与交易相关的同盟者）
- 外包合作伙伴
- 顾客与渠道
- 兴趣社区/团体
- 影响者

对每一方需要考虑：他们的兴趣和动机是什么？他们之间的协同情况如何？在不损害消费者利益的前提下，什么样的方案能够保持与供应商的双赢关系？

**检查相互依赖关系的四个维度：**

| 维度 | 关键问题 |
|------|----------|
| **信任** | 你们之间的承诺是值得依赖的吗？ |
| **同盟** | 双方是否拥有共同的目标？ |
| **灵活性** | 承诺是否能够依据需求的变化而调整？ |
| **权责澄清** | 各方的权责明晰吗？是否达成一致理解？ |

## 9.0 执行——正式组织

### BLM-024 正式组织

**小节：** 9.0  
**关键概念：** 组织架构、管理体系、流程、授权、考核标准、奖励激励

正式组织：为确保关键任务和流程能有效地执行，需建立相应的组织结构、管理和考核标准。

包括：
- 组织架构、管理体系和流程
- 资源和权力如何在组织中分配 — 授权、行权与问责、决策流程、协作机制、信息和知识管理
- 关键岗位的设置和能力要求
- 管理和考核标准：管理幅度和跨度、管理与考评、奖励与激励系统、职业规划、人员和活动的物理位置

## 10.0 执行——人才

### BLM-025 人才

**小节：** 10.0  
**关键概念：** 思想、能力、承诺、关键岗位、人才布局、能力差距

人才：重要岗位的人员要具备相应的能力以完成出色的业绩。

三个维度：思想、能力、承诺。

关键问题：
- 关键岗位和人才布局有什么要求 — 人才需求详细定义
- 人才和能力的差距及挑战 — 欠缺哪些能力
- 获得 — 内部获取、及时培养、外部获取
- 激励与保留

---

## 11.0 执行——氛围与文化

### BLM-026 氛围与文化

**小节：** 11.0  
**关键概念：** 文化、组织氛围、价值观信念、态度行为、社会规范

氛围与文化：创造好的工作环境以激励员工完成关键任务，积极的氛围能激发人们创造出色的成绩，使得他们更加努力，并在危急时刻鼓舞他们。

- **文化** — 社会管制系统、规范（价值、信念）
- **组织氛围** — 对工作环境的感知（态度、行为）
- 影响层面：个人、团队（成功、失败）

**文化变革的杠杆：**
- 领导者行为 — 言行明确并始终如一
- 信息支持 — 信息是否能够支持对的决策和对的行为
- 奖励 — 什么行为/结果会得到奖励，奖励是否真正起到激励作用

**组织氛围维度：**
- 责任感 — 人们可以决定如何完成工作的感觉
- 灵活性 — 鼓励新想法和新方法
- 团队承诺 — 互相帮助、额外努力、相互信任、团队自豪感
- 明确性 — 理解愿景和方向并为之努力
- 标准 — 员工感觉到重点放在改善业绩上并尽最大努力
- 奖励 — 对高绩效的认可

## 12.0 领导力的角色

### BLM-027 领导力的角色

**小节：** 12.0  
**关键概念：** 领导风格多样性、方向、期望值、行为示范、激励氛围

领导力的关键检验问题：

**风格多样性：**
- 提供清楚的方向？
- 树立高的期望值？
- 减少官僚作风？
- 让个人和集体为他们的行为负责？
- 指导个人达到良好的表现？

**行为示范：**
- 领导是否起到了达到结果所需的行为示范作用？
- 领导是否培育了一种激励人心的氛围？

领导力由素质和风格两个维度构成。

## 13.0 一致性分析与根因分析

### BLM-028 一致性分析

**小节：** 13.0  
**关键概念：** 一致性、战略与业务设计、关键任务、正式组织、人才、文化氛围

根据业务设计的要求重新全面思考调整影响执行的各个要素，才能使战略不是纸上谈兵，而是切实保证组织的长短期收益与持续稳定的发展。

**一致性检验框架：**

| 检验关系 | 关键问题 |
|----------|----------|
| 战略&业务设计 ↔ 人才 | 我们有完成任务所需的技能吗？有必要的训练吗？需要找外部资源吗？ |
| 战略&业务设计 ↔ 关键任务 | 基于业务设计，是否清楚知道要完成哪些关键任务？ |
| 关键任务 ↔ 正式组织 | 组织结构支持关键活动的实施吗？需要重新设计组织结构吗？评估体系与战略一致吗？ |
| 战略&业务设计 ↔ 文化氛围 | 价值支持业务方向吗？需要培养哪种文化？ |

当任何一个因素较弱或这些因素间缺乏一致性时，差距就有可能出现。

---

### BLM-029 根因分析

**小节：** 13.0  
**关键概念：** 根本原因、治本不治标、头脑风暴、BLM分类、行动计划

深层原因分析目标：识别差距产生的根本原因并治本——不要只是治标。

分析步骤：
1. 弄清差距：是否都同意、理解并能齐心协力地面对差距？
2. 直觉调查（头脑风暴）：为什么有差距？差距为什么存在？弱点在哪里？
3. 挑战根本原因的每一种假设：为什么？为什么？为什么？
4. 将答案分别归类到BLM的不同部分中去（核对假设的事实和数据，看是否涵盖了所有部分）
5. 检查模型的一致性，识别每一部分中最重要的问题
6. 建立行动计划来淡化最重要的根本原因

通常情况下，差距是由坏的战略造成，或者由于四部分中的一个或多个不协调造成，或是由于执行领导间不协调造成的。

---

### BLM-030 解决方案优先级排序

**小节：** 13.0  
**关键概念：** 优先级排序、影响力、可行性、命中、收获、放弃

解决方案优先级排序矩阵（影响力 × 可行性）：

| | 可行性高 | 可行性低 |
|---|---------|---------|
| **影响力高** | 命中 — 立即行动 | 机会 — 评估后行动 |
| **影响力低** | 收获 — 简单实施 | 放弃 — 暂不考虑 |

影响力标准：改变明显、解决80%的问题、将简化并提升效果  
可行性标准：边界范围内、决策者可控范围、技术上可行、一定时间内合理的回报

## 14.0 业务规划模板

### BLM-031 业务规划模板

**小节：** 14.0  
**关键概念：** 使命愿景、战略目标、市场洞察、业务设计、关键任务、组织能力、风险评估

业务规划模板包含以下模块：

**概述：** 使命、愿景、战略目标、SPAN、BCG/GE矩阵、FAN

**市场洞察：** 宏观分析、竞争动向、客户分析（市场/客户细分、偏好、购买习惯）

**业务设计：**
- 客户选择
- 价值主张
- 价值获取
- 活动范围
- 价值持续增值
- 业务风险管理

**业务方案组合战略：** 业务开发、业务流程、产品路线图

**执行：**
- 关键任务和相互依赖关系
- 构建组织能力
- 风险评估
- 结果衡量、关键里程碑

**重大项目：**
- 业绩目标：收入、利润
- 市场渗透：份额项目
- 市场拓展：插旗项目
- 新品开发：山头项目
- 双新项目

**预测差距：** 业绩差距、机会差距
