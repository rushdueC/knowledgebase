## 1.0 市场管理流程六个步骤概述

### MM-001 市场管理的定义与价值实现六个领域

**小节：** 1.0  
**关键概念：** 价值实现六个领域、选择价值、创造价值、提取价值、宣传价值、交付价值、理解价值、协调价值实现活动

市场管理是一种系统的方法，用于对广泛的机会进行选择收缩，制定出一套以市场为中心的、能够带来最佳业务成果的战略与计划。市场管理在协调价值实现的六个领域起着非常重要的作用，这六个领域是：选择价值、创造价值、提取价值、宣传价值、交付价值和理解价值。

市场管理流程的目的是为公司所有产品线、产品族及产品营销计划实现价值创造提供一致的分析，使公司能够通过明智的投资创造最大的价值。

六个价值领域：

| 序号 | 价值领域 | 市场管理活动 | 非营销活动 |
|------|----------|-------------|-----------|
| ① | 选择价值 | 战略及产品线规划 | 财务和战略 |
| ② | 创造价值 | 产品包管理和产品线管理 | 开发 |
| ③ | 提取价值 | 产品包管理和产品线管理 | 财务 |
| ④ | 宣传价值 | 渠道启动和产品线管理 | 宣传和销售与技术支援渠道 |
| ⑤ | 交付价值 | 渠道启动和产品线管理 | 销售与技术支援渠道 |
| ⑥ | 理解价值 | 战略及产品线规划 | 财务和战略 |

### MM-002 市场管理流程的本质——业务流程

**小节：** 1.0  
**关键概念：** 投资分配决策、业务流程、市场细分规则、优先级排序、可执行业务计划

市场管理规划的目的是为整个公司的价值创造活动提供一致的分析。核心问题包括：公司的投资如何分配到各产品线是最明智的？公司将如何作出决策？

市场管理流程是一道业务流程，它运用严格、规范的方法对市场走势及业务要求及需求进行分析，创建合理的市场细分规则，对要投资和取得领先地位的细分市场进行选择和优先级排序，从而制定可执行的业务计划。通过从业务流程的角度定义确保市场营销取得成功需要执行的活动，制定可盈利、可执行的业务计划和驱动新产品包的开发，这道流程能够使一个公司或产品线的各项举措成功地付诸实施。

---

### MM-003 流程的通用性与关键成功要素

**小节：** 1.0  
**关键概念：** 通用流程、跨层次执行、客户需求、管理架构、生命周期管理团队(LMT)

该流程是一个通用的流程，可用于不同层次的业务，关键成功要素在于跨以下层次贯彻和执行：公司（公司是一个整体）、产品线、细分市场、产品包/解决方案领域。

流程的一个关键成功要素是客户需求，以及向产品线业务计划制定者宣传客户需求。市场管理流程为以下三个环节提供一个管理架构：1.选择市场和（或）细分市场；2.制定满足客户需求的产品包/解决方案战略；3.创建/执行可盈利业务计划和评估绩效。该架构可应用于产品包/解决方案领域及以上层次的领域，包括公司层次。

通过执行市场管理流程，产品线对市场、客户需求和竞争对手有了更深入的了解，从而能够选择客户最看重的产品包/解决方案进行投资，并投资于必要的营销、开发、联盟和销售活动，将产品包/解决方案推向市场。接下来由生命周期管理团队（LMT）管理产品包/解决方案的生命周期，满足绩效目标的要求。

### MM-004 流程关联——与IPD、ISC、CRM等下游流程的关联

**小节：** 1.0  
**关键概念：** IPD、ISC、CRM、流程关联、IRB、IPMT、PMT、PDT、LMT、渠道管理、技能管理、供应商管理、机会管理、关系管理

市场管理流程与其他规划和业务处理流程有关联，这些关联有助于确保正确的制定、执行决策，及必要时修订决策。

主要关联包括：

- **产品开发（IPD）：** 从概念阶段一直到生命周期终止的产品包/解决方案开发
- **IPD管理体系：** IRB、IPMT、PMT、PDT和LMT
- **渠道管理：** 有效执行具体产品包/解决方案的分销战略
- **技能管理：** 为选定的解决方案和细分市场规划技能战略
- **供应商管理：** 确保有供应商为所选的解决方案提供支持
- **产品包信息：** 可以获得选定的解决方案信息
- **信息管理：** 能够获取所需数据
- **机会管理：** 通过优先排序编码评估机会点
- **关系管理：** 根据选定的细分市场和计划确定有依赖关系的活动
- **规划营销活动：** 制定综合营销宣传战略和计划
- **订单履行流程：** 制造和交付产品包和/或解决方案
- **投资管理体系（财务）：** 投资跟踪系统

组织关联：与主要业务要素的关联，包括事业部、战略规划、开发、财务和销售。

### MM-005 市场管理流程六个主要步骤

**小节：** 1.1  
**关键概念：** 六步骤、了解市场、市场细分、组合分析、业务战略和计划、跨产品线融合、评估绩效、使能器

市场管理流程活动可分成以下六个主要步骤：

1. 了解市场
2. 进行市场细分
3. 进行组合分析
4. 制定业务战略和计划
5. 跨产品线融合和优化业务计划
6. 管理业务计划，评估绩效

**流程目的：** 通过该流程，及时、有效地将市场需求转化为领先的产品包/解决方案，满足或超出客户期望。

**输入：** 当前市场细分组合、市场数据信息、所有公司战略、业务、技术、架构、业务能力

**输出：** 更新的业务计划、更新的产品假设、书面记录的流程优化

**使能器：** 通用数据定义、流程联系、推行指导书、组合分析、客户$APPEALS、项目管理、共用基础模块、以用户为中心的设计

### MM-007 设计原则

**小节：** 1.2  
**关键概念：** 设计原则、基于团队的管理、基于事实的决策、品牌价值、客户满意度

设计原则重点关注于有效性和效率，包括：

- 实现业务目标：全球所有客户都能访问同一个公司
- 给公司战略提供更多的客户需求输入
- 贯彻基于团队的管理体系
- 使用基于事实的决策工具
- 开发可提高品牌价值与忠诚度的有竞争力的产品包和解决方案
- 在世界上任何地方都能在适当的时间以适当的成本提供合适的技能资源
- 将销售渠道重点集中在全球适当的客户细分市场，并帮助他们获得成功
- 在世界范围内共享资源和信息
- 满足客户必要的需求：履行承诺、易于交易、了解客户、反应迅速可获得、宣传表现出色

### MM-008 市场管理的起点和终点

**小节：** 1.3  
**关键概念：** 高层配合、持续流程、投资决策审视

市场管理流程的启动应得到高层的配合，该高层认识到有必要了解市场，提高收入、利润和客户满意度。他/她希望通过一个统一的流程来管理业务，从而：了解市场、制定和执行满足客户需要和需求的业务战略和计划、评估各业务计划的执行情况并进行必要的调整。

市场管理流程实际上是没有结束的时候，因为外部环境在不断的变化，促使管理层不断的重新评估客户需要和需求。团队可以通过该管理体系不断的对投资决策进行审视。

### MM-009 市场管理流程的用户

**小节：** 1.4  
**关键概念：** IPMT、MA、PMT、UCD、用户分类、下游流程

市场管理流程的主要用户分为三类：

**1. 管理业务部门表现的人：** 执行集成组合管理团队（IPMT）角色的资源，使用市场管理流程的输出进行投资决策、审批业务计划、执行业务计划并评估计划执行情况。

**2. 战略和计划的制定者：** 执行市场分析（MA）角色的资源，负责流程中的研究和分析活动；执行组合管理团队（PMT）角色的资源，主要负责产品线规划活动和绩效管理。

**3. 下游流程的执行者：** 包括开发人员（根据客户需求开发产品包/解决方案、发布并推出产品包/解决方案）、销售渠道（通过有效渠道交付价值承诺、制定客户计划、将销售精力集中在选定的细分市场）、以用户为中心的设计（UCD）、人力资源等。

### MM-010 业务计划框架

**小节：** 1.5  
**关键概念：** 业务计划框架、七个部分、产品线业务计划、细分市场业务计划、产品包/解决方案业务计划、核心要素、运营要素、评估要素

业务计划架构为所有产品线制定各自的业务计划提供了一个统一的方法，由互为补充的七个部分组成：

| 类别 | 要素 |
|------|------|
| **核心要素** | 1. 产品包 |
| | 2. 定价/条款 |

| **运营要素** | 5. 支持/技能 |
| | 6. 履行 |
| **评估要素** | 7. 绩效评估与风险评估 |

业务计划框架支持三种结构类似的业务计划：产品线业务计划、细分市场业务计划和产品包/解决方案业务计划。业务计划总结为10到20页的总结文档，用于管理评审、战略流程和预算流程。

### MM-011 三种业务计划的使用

**小节：** 1.6  
**关键概念：** PLBP、SBP、O/SBP、IO/SBP、PDT、IPD流程、IPMT审批

**1. 产品线业务计划（PLBP）：** 记录产品线所参与的市场情况，制定了相关和附属组织应遵循的战略和计划。在产品线内优化计划组合，确保组合满足或超过产品线的绩效目标。总结部分作为战略和预算流程的一部分，在高层管理人员评审时使用。

**2. 细分市场业务计划（SBP）：** 跨多个产品线的细分市场或一个产品线的细分市场的业务计划。用于记录能够驱动细分市场中业绩的战略、计划和主要产品包/解决方案。未必适合于所有产品线（如业务或细分市场规模不够大）。

**3. 产品包/解决方案业务计划（O/SBP）：** 为单个产品线和/或细分市场内的具体机会点制定。完成分两个阶段：初始产品包/解决方案业务计划（IO/SBP）和最终产品包/解决方案业务计划。IO/SBP形成于市场管理流程，通过IPMT审批，在IPD流程中由PDT最终定稿。一旦IO/SBP审批通过，便组建项目开发团队（PDT），开始最终O/SBP的工作。

### MM-012 业务计划评估

**小节：** 1.7  
**关键概念：** 业务计划评估、平衡积分卡、绩效跟踪、纠错措施、流程优化

一旦制定、批准了业务计划，市场管理流程要求评估业务计划，以确保计划的执行和有效的管理。包括评估业务计划表现和制定必要的纠错措施，还包括评估流程有效性和制定计划持续优化流程。

使用平衡积分卡的方法来跟踪业务计划的表现，使管理人员能够查看到所有产品线、细分市场和产品包/解决方案的表现。应根据相关业务计划的目标来评估绩效，包括收入、利润、市场份额、客户满意度和忠诚度、营销效率、技能资源等。

产品线的营销高层负责确保业务计划满足绩效目标，根据市场变化和内部变化调整业务计划，在业务计划中反映出变更，并知会所有受影响的部门。

## 2.0 市场管理流程角色

### MM-013 市场管理流程角色概述

**小节：** 2.0  
**关键概念：** IPMT、MMC、MA、FA、PMT、角色与岗位的区别

角色定义了市场管理流程中的角色，不是描述营销职业生涯中的职业、岗位或头衔，而是描述流程所定义的角色。角色应该由内部或外部掌握有营销技能的合格个体（可以是人或部门）来执行。在所选机会的寿命内，一个个体可执行不只一个角色，也可有多个个体同时执行同一个角色。

市场管理流程中的主要角色：

1. 集成组合管理团队（IPMT）角色
2. 市场管理协调员（MMC）角色
3. 市场分析（MA）角色
4. 财务分析（FA）角色
5. 组合管理团队（PMT）角色

流程角色并不等同于岗位头衔。通过对角色的定义，流程保持了足够的通用性，以便所有组织都能使用该流程。任何受过正规培训的营销专业人员任何时间都能执行流程角色。

---

### MM-014 集成组合管理团队（IPMT）角色

**小节：** 2.0  
**关键概念：** IPMT、产品包组合、投资决策、IRB、PDT管理、跨功能部门

IPMT角色负责产品线、细分市场或产品包/解决方案层次的产品包组合在全球的业绩。IPMT角色通过确立产品线愿景、使命和目标，确定了跨功能部门团队的方向。IPMT角色是跨功能部门团队的成员之一，由代表全球硬件和软件开发、营销、销售、生产/订单履行、采购、财务和其他功能领域的高层人员组成。

核心职责：

- 公司给IPMT提供战略和架构的指导，组建跨功能部门高层团队（IRB）管理产品线组合和产品包开发
- 在选定的细分市场，根据业务增长、盈利性、资源可获得性和风险情况作出持续业务投资决策
- 开展市场管理流程中的多数审批和高层决策活动
- 对细分市场和为满足细分市场内客户需要和需求而开发的产品包/解决方案负有主要责任
- 通过正式的决策评审合理进行产品线组合，审批和执行战略和业务计划
- 负责及时解决业务团队结构内产品线管理和关键跨产品线项目的问题
- 将营销和业务计划与产品包/解决方案的开发相融合
- 获得了承诺和未承诺的资源清单，并在IPD决策评审点分配给PDT
- 激励和管理PDT的绩效和表现

### MM-015 市场管理协调员（MMC）角色

**小节：** 2.0  
**关键概念：** MMC、流程推行、经验教训总结、流程剪裁

市场管理协调员关注如何在产品线内很好地推行流程。协调员通常是IPMT成员，是负责在产品线内市场管理推行的经理或高层人员，多数情况下由营销副总裁担任。

核心职责：

- 就如何改进流程的推行和执行向产品线提出建议
- 评估流程的推行情况，进行经验教训总结
- 增强产品线内流程推行的力度
- 根据产品线的实际情况有限度地剪裁市场管理流程
- 进行产品线流程归档

### MM-016 财务分析（FA）角色

**小节：** 2.0  
**关键概念：** FA、财务分析、绩效分析、IPMT和PMT顾问

FA角色负责进行财务分析，支撑市场管理流程，多数情况下由财务专业的财务分析员担任。

核心职责：

- 收集、分析相关财务数据
- 充当IPMT和PMT的顾问
- 提供有关战略和计划的财务成本信息，协助制定业务计划
- 针对业务计划目标，持续提供绩效分析和评估

### MM-017 市场分析（MA）角色的子角色

**小节：** 2.0  
**关键概念：** MA、竞争分析、市场细分、市场需求、客户情报、销售渠道、解决方案开发、联盟发展、计划员、技术角色

市场分析角色可进一步分为以下不同子角色：

1. **竞争性/竞争对手分析和市场情报：** 向公司提供对竞争对手的竞争性分析，包括联盟和合作的影响、竞争产品路标、市场趋势分析、对比竞争对手产品和公司组合。
2. **市场细分：** 根据营销团队各成员的调查和所提供的信息细分客户。
3. **市场需求：** 管理市场调研项目，了解客户购买行为、产品特性需求和采购决策标准。执行需求管理流程5个步骤中的前3个步骤（收集、分析和分发），开发和管理市场需求。
4. **客户情报分析：** 管理客户数据库开发，提供专门报告，分析行业纵向联合、购买行为、产品销售和特色组合等发展趋势。
5. **销售渠道/业务伙伴：** 接触销售渠道和业务伙伴了解客户对解决方案的需求并反馈给PMT，制定并执行计划将产品作为渠道和业务伙伴解决方案的一部分。
6. **解决方案开发：** 与产品线和业务项目接口，了解客户对解决方案的需求并反馈给PMT。
7. **联盟发展：** 列出可以合作的公司并结成联盟，管理与所确定公司间的所有活动。
8. **计划员：** 规划产品的系统管理需求。
9. **技术：** 技术需求和新技术。

MA角色负责调查和分析产品包、竞争、经济/人口和市场调研的数据，具备调查、分析和咨询的技能，向IPMT和PMT提供支撑和建议。

---

### MM-018 组合管理团队（PMT）角色

**小节：** 2.0  
**关键概念：** PMT、市场细分架构、组合模型、优先排序、战略计划、PMT经理、三类资源

PMT角色负责定义所选细分市场的市场细分架构，并确定组合模型的标准和权重。使用组合分析数据对相关子细分市场进行优先排序，负责制定业务战略和计划。分析业务计划的绩效并建议纠错措施。

3类资源执行PMT角色：

| 类型 | 人员 | 负责制定 |
|------|------|----------|
| 1 | 营销副总裁 | 集团或范畴的战略计划 |
| 2 | 营销副总裁或营销经理 | 产品线和/或细分市场的战略计划 |
| 3 | 营销经理 | 具体产品包/解决方案的战略计划 |

在各步骤中的参与：

- 步骤1（了解市场）：竞争/竞争对手分析和市场情报角色、市场需求角色和客户情报分析角色起重要作用
- 步骤2（进行市场细分）：由市场细分角色完成
- 其余步骤：市场分析角色和财务分析角色中的所有角色都将参与

## 3.0 理解市场

### MM-019 理解市场——概述

**小节：** 3.0  
**关键概念：** 理解市场、PL-IPMT、市场评估文档、使命与目标、环境分析

这一步骤用于对市场进行概要描述，包括了解和评估市场的经济、行业、竞争对手、客户和产品线机会。

**目的：** 促进IPMT加强对自己所运作的环境的了解，并对该环境进行明确描述，有助于产品线细分市场并进行优先排序。

**输入：**

- 业务方向（PL-IPMT给予整体业务方向指导）
- 客户需要和需求（未来1到3年的概括性客户需要和需求是整个流程的驱动器）
- 市场和竞争信息（市场趋势、竞争对手和客户行动、环境变化等）
- 产品线当前的业务计划和组合

**主要角色：** IPMT（定义愿景、使命和目标）；MA（第二重要角色，进行市场环境分析）；MMC。

**活动：**

- A. 定义和整合使命和目标（IPMT）
- B. 进行市场分析（MA）

**输出：** IPMT角色归档产品线的愿景、使命和目标；市场分析角色归档对环境的评估（市场评估文档）。

**使能器：** 宏观环境分析、竞争分析、公司自身分析、市场分析、SWOT分析、市场地图、业务设计

---

### MM-020 定义并融合使命与目标

**小节：** 3.1  
**关键概念：** 使命、目标、五个要素、差异化能力、利润模型、战略控制点

该步骤包括形成不同功能领域中各IPMT成员一致同意的使命和目标。使命和目标是产品线在今后几年应遵循的大致方向，也提供了制定业务计划所依托的架构。

使命描述的5个要素：

1. **产品线角色和对公司的贡献：** 多数情况下产品线认为自己是利润生成者，也可能是机会寻找人/促成人
2. **业务描述（附加价值）：** 关注于产品线直接回应客户优先业务需求时所带给客户的益处
3. **差异化能力：** 加固成功的主要技能/能力/资源，团队通常会列出2到4条原因描述为什么客户选择公司的产品
4. **利润模型和战略控制：** 当前价值与竞争差异和战略控制点的关联
5. **未来指示标（优先级）：** 预测产品线的主要优先级

目标可以从以下角度描述：收入和其他财务、市场、产品/技术、产品线贡献、市场细分模型、组织、合作伙伴等。

**输出：** 归档的产品线使命和目标（参照使命和目标模板）。

---

### MM-021 进行市场分析——概述与工具

**小节：** 3.2  
**关键概念：** 环境分析、竞争分析、公司自身分析、市场分析、波特五力模型、产品生命周期(PLC)、SWOT、核心产品、周边产品包

通过全面调研，清楚地了解市场。根据所收集的信息，对市场动力（经济、行业、竞争对手和客户）进行评估。该步骤提供了后续分析活动所需要的基础数据。

市场评估包含四个分析维度：

**1. 环境分析：**

- 政治（财务政策、法制、力量集团等）
- 经济（国家/全球经济增长、利润率、汇率等）
- 社会（文化、宗教、生态、人口等）
- 技术（新产品、新工艺流程、替代技术等）

**2. 竞争分析：** 了解市场上主要竞争对手，确定规划阶段的主要竞争对手，描绘出他们的能力和意图。可使用波特五种力量模型（供应商的议价能力、现存公司间的竞争、购买者的议价能力、新入行者的威胁、替代产品的威胁）。

**3. 公司自身分析：** 关注4个方面——本年度和三年目标、财务状况（收入和营业利润）、产品生命周期（PLC）、组合。核心产品与周边产品包（服务产品包和无形产品包）的分析。

**4. 市场分析：** 确定市场的驱动力和主要趋势，关注市场规模、增长和趋势、特点和拓展、客户细分市场/需求、购买者行为、中介和价值网。

---

### MM-022 SWOT分析——优势与劣势分析

**小节：** 3.2  
**关键概念：** SWOT、优势、劣势、客户重要性矩阵、定性分析、优先排序

通过收集信息和对信息进行分析，团队可以评估产品线优劣势。优劣势分析应针对各主要竞争对手进行。此阶段中的S&W分析倾向于定性分析，组合分析步骤给优劣势分析添加了定量的内容。

考虑方面：产品、促销/形象、定价/条款、分销、订单履行、服务和支持。

客户重要性矩阵：

- 对客户非常重要的优势 → 作为优势点
- 对客户较重要的优势/劣势
- 对客户不重要的优势/劣势

列出优劣势后，根据对客户的重要性进行优先排序。对客户比较重要的劣势点，团队需确定补救方法。这些优势点和补救方法会成为以后设计行动计划的依据。

---

### MM-023 SWOT分析——机会和威胁分析

**小节：** 3.2  
**关键概念：** 机会、威胁、业务影响、发生可能性、使命重新审视

根据通过外部分析（环境、市场和竞争分析）所获得的信息，团队能够确定产品线所面临的机会和威胁，以及影响业务的主要因素。

优先排序标准：根据对产品线的潜在业务影响和这些机会和威胁出现的可能性进行排序。

团队需要考虑：

- 产品线目前目标合适否
- 形成市场和竞争产品的主要驱动力
- 对应于产品线目前和今后三年差异化优势的主要机会点
- 在选定的机会领域产品线所面临的威胁
- 市场上没想过要去争取的领域及原因

在此，团队应根据所有收集到的信息和分析对使命和目标进行重新考虑，因为这个步骤可能会反映出目前业务方向中的严重缺陷。

---

### MM-024 市场地图

**小节：** 3.2  
**关键概念：** 市场地图、价值链、购买机制、分销渠道、影响者

根据对产品线所经营的竞争市场的分析和了解，团队可以描绘出市场上的产品的流动情况——即市场地图。团队记录了在其定义的市场上，和希望进行规划的市场上作出购买决策的所有重要阶段。

市场地图定义了市场动力、制造商与最终用户间的价值链，并考虑了市场上所发现的各种购买机制，也包括与分销渠道和影响者有关的部分。重点突出了直接销售和通过有关渠道分销的产品量和价值，指出了拓展市场的潜在机会。

描绘方法：

1. 描绘有关自己业务的布局图，包括现有和潜在客户群、渠道机制和主要影响者/建议者
2. 用线绘出目前开展业务时产品上市的真正路径，标出每条线每年所携带的价值
3. 用另一种颜色添加近三个竞争对手，包括他们不同的渠道合作伙伴和主要客户

---

### MM-025 业务设计评估

**小节：** 3.2  
**关键概念：** 业务设计、客户选择、价值定位、利润模型、战略控制点、范围、组织体系

市场分析的最后一部分是评估产品线当前的业务设计。业务设计关注四个领域：

1. **客户选择和价值定位：** 可以为哪些客户增加实际价值并可以盈利？不愿服务于哪些客户？
2. **价值获取/利润模型：** 如何获取所创造的一部分价值作为利润？利润模型是什么？
3. **差异/战略控制：** 客户为什么购买产品？价值陈述与竞争对手的差异在哪里？战略控制点是什么？如何保护利润流？
4. **范围：** 要卖什么产品、服务和解决方案？哪些活动由自己执行，哪些与合作伙伴一起执行？

**组织体系：** 什么样的组织体系能提供最好的支持？考虑因素包括绩效评估、组织结构、文化、主要技能/人员要求、与公司的关系等。

---

## 4.0 进行市场细分

### MM-026 进行市场细分——概述

**小节：** 4.0  
**关键概念：** 市场细分、细分变量、评估标准、独特性、重要性、可衡量性、持久性、可识别性、$APPEALS

这个步骤包括确定结构，用这个结构来进一步分析市场、收集信息，对机会进行排序和选择。在确定结构时，产品线必须使用一致的细分变量和评估标准。本步骤包括针对所有市场/细分市场的市场情报收集和标准数据准备。

**目的：** 确定市场细分的纲要、确定/获得组合分析模型、收集和准备各细分市场的数据、确定用于细分市场组合分析的评估标准和权重。

**输入：** 使命描述与市场定义、市场评估的结论、市场地图

**主要角色：** 组合管理团队（PMT）；次要角色：市场和财务分析、业务部门管理和IPMT角色

**活动：**

- A. 确定分析结构与框架（PMT）
- B. 获得、评估和准备组合分析模型的数据（MA）

**输出：** 批准的市场细分框架、初步选定的细分市场、每个所选细分市场的概貌、初始客户$APPEALS分析、公司和竞争对手产品/产品包与每个细分市场映射

所定义的细分市场必须满足独特性、重要性、可衡量性、持久性和可识别性要求。

---

### MM-027 市场细分基本原理

**小节：** 4.1  
**关键概念：** 人口统计、行为/所有权、需要、消费心态、三个维度、谁买什么为什么

通常有多种方法对市场进行细分，每种方法各有长短：

| 方法 | 优点 | 缺点 |
|------|------|------|
| **人口统计** | 更容易分辨和获取 | 只能回答谁，不能回答为什么和什么 |
| **行为/所有权** | 能提供市场机会和规模信息 | 缺少为什么的信息 |
| **需要** | 能最清楚指明应该销售什么与如何定位 | 区分不出目标性特征 |
| **消费心态** | 能清楚提供人群类别图画 | 很难与产品或服务紧密联系 |

在定义业务计划要素时可以使用多种市场细分方法来确定战略。市场细分框架应包含3个维度：**谁**（客户类型和大小）、**什么**（产品包的差异化特性）、**为什么**（给客户带来的好处顺序）。

---

### MM-028 市场细分流程七步骤

**小节：** 4.1  
**关键概念：** 七步骤、Pareto效果、微型细分市场、好处分类、可行性测试、独特性、重要性、可衡量性、持久性、可识别性

市场细分的识别与选择流程分为7个步骤：

**第1步：审视市场细分框架** —— 从公司高层获得有力指导，明白各种市场细分框架的影响。预期80:20的Pareto效果，只关注最好的机会。

**第2步：确定谁购买** —— 寻找单独分类或分类组合（地域、业界标准、工作/职责、公司规模等）。一般建议把数量控制在最多10个以内。

**第3步：确定买什么** —— 列出所有重要产品/产品包，描述在哪里购买、采购频率/环境、采购方法和采购部门。然后找出客户使用的主要特性或特性组，确定10-15种模式。

**第4步：确定谁买什么** —— 将每个谁与真正重要的买什么组合，产生大约100-150个微型细分市场，通过甄别吸引力、合并、取消来减少到12-15个最有吸引力的初步细分市场。

**第5步：判断为什么购买** —— 分析客户行为，关注基于需要的好处。好处分类：给公司带来的好处、标准上的好处、差异化带来的好处。

**第6步：确定主要细分市场** —— 描述并解释对大约10个细分市场的选择原因，选择明显、简短和易于描述记忆的名称。

**第7步：测试可行性** —— 验证每个细分市场的独特性、重要性、可衡量性、持久性和可识别性，以及可行性（能否明确确定、能否衡量、规模是否够大、能否作为通用的销售渠道、能否开发产品包等）。

---

### MM-029 记录评估和准备组合分析模型数据

**小节：** 4.2  
**关键概念：** 细分市场概要、$APPEALS、价格、可获得性、包装、性能、易用性、保证、生命周期成本、社会接受程度、产品包对应图

该子流程使团队根据确定的市场细分轮廓为下一步——进行组合分析做好准备。团队应保证掌握了所选细分市场的充分数据，以进行组合分析活动。

每个所选细分市场的概要描述应包括：名称、机会、增长率、公司市场份额、主要买家、增值/业务模型、业务驱动力、客户面对的业务问题、当前产品包、购买标准、主要竞争对手。

**客户$APPEALS框架：**

| 字母 | 含义 |
|------|------|
| $ | 价格 |
| A | 可获得性 |
| P | 包装 |
| P | 性能 |
| E | 易用性 |
| A | 保证 |
| L | 生命周期成本 |
| S | 社会接受程度 |

$APPEALS框架能够使团队：处理目标细分市场的全部客户欲望与需要；建立客户驱动的需求集；确定主要分界标准；确定促使客户选择产品包的主要差异。

**产品包与细分市场对应图：** 明确公司和竞争对手销往每个细分市场的产品包，确定各竞争对手每个产品包的相对市场占有率，了解公司哪些产品面向不同细分市场，确定财务分析的分配方法。

## 5.0 进行组合分析

### MM-030 进行组合分析——概述

**小节：** 5.0  
**关键概念：** 组合分析、SPAN、FAN、市场吸引力、竞争地位、投资/停止投资决策

这一子流程包括把所有细分市场标准数据输入到分析模型中，使用这个模型并分析结果。主要流程的结果是细分市场的选择。

**目的：** 对细分市场和机会进行优先级划分，以便产品线能够选择机会和细分市场进行投资。应当与市场专家一起评审模型输出，确保细分市场分析是现实和客观的。

**输入：** 使命陈述和市场定义、经过可行性验证的初步细分市场、每个选定细分市场的概述、初步细分市场的市场和财务数据

**主要参与者：** IPMT、MMC和PMT角色；次要角色：MA角色

**活动：** 进行SPAN和FAN分析——将现有产品包和解决方案与所确定的细分市场进行匹配，进行战略定位分析（SPAN），评估市场吸引力、评估竞争地位、评估产品线能力，进行财务分析（FAN），评估财务业绩，找出差距和重叠，作出投资/停止投资决策。

**输出：** 选定的并经过优先级划分的细分市场清单，以及支撑依据。

### MM-031 战略地位分析（SPAN）——四种宏观战略态势

**小节：** 5.1  
**关键概念：** SPAN、增长/投资、获取技能、收获/重新细分、避免/退出、市场吸引力、竞争地位、分销、成本控制、研发、市场份额

SPAN帮助产品线确定针对每个细分市场应当有什么宏观战略态势。可用两个维度评估每个细分市场：市场吸引力（市场规模、增长率、潜在利润和战略意义）和竞争地位（差异能力和保持成本/资产优势的能力）。

四种宏观战略态势：

**1. 增长/投资：** 细分市场总是赢利的，有吸引力且产品线有很强竞争优势。主要战略行动是防止新对手进入。应扩大分销渠道、扩大生产和投资、严格控制成本、继续研发投资、加大营销工作。

**2. 获取技能：** 细分市场通常还未赢利，有吸引力但竞争优势较弱。需要削减费用，改善赢利能力。主要战略行动是提高竞争地位。应限制分销覆盖面、对生产研发和人力投资、积极定价和促销以获得市场份额。

**3. 收获/重新划分细分市场：** 细分市场通常仍然赢利，没有吸引力但有很强竞争优势。需要提高回报。主要战略行动是整合机会并提高运作效率。应维持现有分销模式、重点运作效率、限制营销活动、研发重点放在降低成本。

**4. 避免/退出：** 细分市场几乎总是亏损的，没有吸引力且竞争优势较弱。应当退出。主要战略行动是管理现金流和回报。应逐渐撤销分销、大力削减成本、减少或停止产能和研发费用。

### MM-032 SPAN市场吸引力评估要素

**小节：** 5.1  
**关键概念：** 市场吸引力、市场规模、市场增长率、利润潜力、战略价值、权重系数、直接/间接竞争、进入威胁、客户/供应商压力

有四个要素被用来评估每个细分市场的吸引力：

1. **市场规模：** 评级（高、中、低）反映细分市场的相对收入机会。
2. **市场增长率：** 评级反映细分市场以后三年的年度复合增长率（CAGR）。
3. **利润潜力：** 分为三个子要素：
   - 直接/间接竞争：考虑领导者市场份额、竞争对手数量、差异化程度、替代解决方案
   - 进入威胁：考虑参与者平均税前收益、初始资本、渠道/市场获得的数量、架构标准
   - 客户/供应商压力：考虑价格敏感性、客户数量、供应商对关键资源的控制
4. **战略价值：** 评级反映这一细分市场对产品线和整个公司的战略价值/重要性。

权重系数之和应当是100。将高、中、低评分转换为5、3、1分数后，乘以权重系数，得到SPAN图中每个细分市场的市场吸引力得分。

---

### MM-033 SPAN竞争地位评估——客户关键成功要素(CSF)方法

**小节：** 5.1  
**关键概念：** CSF、竞争地位、业界最佳(BOB)、7步骤、竞争地位比率、评分换算

对于竞争地位，可以用客户关键成功要素（CSF）对每个细分市场进行衡量，包括7个步骤：

1. 确定并列出CSF、公司产品包和业界最佳(BOB)竞争对手产品包
2. 按照100分制对CSF进行优先级划分
3. 针对每个CSF，将公司产品包和BOB产品包评级（使用1-10评分标准，10最好，1最差）
4. 将CSF优先级乘以公司得分，计算出每个CSF的公司得分
5. 将CSF优先级乘以BOB得分，计算出每个CSF的BOB得分
6. 计算出公司和BOB的总分
7. 将公司总分除以BOB总分，算出竞争地位比率

评分换算：

| 评分 | 含义 |
|------|------|
| 8 | 不寻常的，突破性的质量 |
| 7 | 独立的领先者 |
| 6 | 与前1-2名竞争对手共享领先地位 |
| 5 | 与前3-5名竞争对手共享领先地位 |
| 4 | 非常好，大多数人完全接受 |
| 3 | 一般，80%的购买者可以接受 |
| 2 | 勉勉强强，只有65%的购买者会接受 |
| 1 | 分界线，质量差 |

---

### MM-034 SPAN竞争地位评估——客户$APPEALS方法与价值差异化评估

**小节：** 5.1  
**关键概念：** $APPEALS、价值差异化、基本需求、令人满意的需求、吸引人的需求、差距分析、BOB、三个维度

第二种方法衡量竞争地位：客户$APPEALS。$APPEALS使用客户欲望和需求框架，分细分市场来了解购买行为和产品包竞争力。

进行客户价值差异化分析的六个主要步骤：

1. 针对$APPEALS八项中的每一项，确定主要的客户需求
2. 将客户需求按优先级划分为三类：基本需求、令人满意的需求、吸引人的需求
3. 为$APPEALS中的每一项分配一个权重，反映其对客户的相对重要性
4. 根据每个产品包是否很好地满足客户需求，评定公司和业界最佳(BOB)竞争对手产品包
5. 算出每一项的公司和BOB得分，并累加得出整体分值
6. 将公司整体分值除以BOB竞争对手整体分值，得出最终的客户价值差异化要素值

**差距分析：** 差距分析不是将产品线同竞争对手对比，而是对比产品线和竞争对手在满足客户需要方面分别做得怎么样。了解为什么可以帮助产品线获得竞争优势和差异化优势。

SPAN图中的圆圈大小代表每个细分市场的市场空间大小（第三个维度）。

### MM-035 财务分析（FAN）

**小节：** 5.1  
**关键概念：** FAN、内部收益率(IRR)、税前利润(PTI)、累计收入、最低投资回报率、现金流、基线预测

财务分析(FAN)对进入的每个细分市场进行量化地财务分析，它对比每个细分市场的预期收益比例和其累计收入：

**收益比例：** 细分市场的内部收益率(IRR)是税前利润(PTI)或现金流与某个细分市场上销售的所有产品线产品包的比率。

**累计收入：** 基于每个产品包的收入，每个细分市场的预期收入。可用来衡量产品线在某细分市场上竞争所产生的运营现金流出。较高的累计收入将产生较高的现金流。

通过把收益比例和累计收入映射到FAN图，团队根据财务结果对每个细分市场进行地位描述。FAN图展示了相对于公司的资本成本或者最低投资回报率，某细分市场的财务收益。

SPAN和FAN相辅相成：

- FAN回答：我是否在所服务的细分市场赚钱？回报是否超过了资本成本？
- SPAN回答：该细分市场的吸引力有多大？产品包定位得怎么样？

当前的SPAN和FAN地位可以用来作为基线，预测战略行动的结果和每个细分市场的目的和意图。

## 6.0 制定业务策略和计划

### MM-036 制定业务策略和计划——概述

**小节：** 6.0

这是市场管理流程里面的一个主要子流程，包括：进行所需要的研究和分析，确定什么产品包/解决方案对细分市场和/或事业部是最重要的；制定业务计划（产品线业务计划、细分市场业务计划、产品包/解决方案业务计划）。

  6. 制定订单履行策略和计划
  7. 制定经营情况/风险评估
  8. 归档业务策略和计划
  9. 分发业务策略和计划

**输出：** 批准通过的产品线内部的业务计划（产品线业务计划、细分市场业务计划和/或产品包/解决方案业务计划）。

### MM-037 制定业务策略——安索夫矩阵

**小节：** 6.1  
**关键概念：** 安索夫矩阵、市场渗透、市场开发、产品开发、多样化、缺口分析、运作缺口、新策略缺口

安索夫矩阵是一个2乘2的矩阵，通过评估公司面对的增长策略选择，为支持目标提供了一个框架。两个维度是：市场/细分市场的新旧和产品/技术的新旧。

四类营销目标：

| 象限 | 策略 | 特点 |
|------|------|------|
| 1 | 市场渗透 | 现有市场上出售现有产品（快速、低风险、低成本） |
| 2 | 市场开发 | 将现有产品卖到新市场（较缓慢、风险较大、营销行动投资） |
| 3 | 产品开发 | 向现有市场出售新产品（研发投入、快速） |
| 4 | 多样化 | 向新市场出售新产品（高风险、昂贵） |

缺口分析的两个方面：

- **运作缺口：** 包括改进效率和市场渗透，通常以最低廉的成本和最小的风险保证销售增长
- **新策略上的缺口：** 包括市场开发、产品开发和多样化

团队应先按当前方向与速度确定3年收入目标，按安索夫矩阵确定每个目标细分市场未来三年的收入目标，然后检查收入缺口是否已关闭。

### MM-038 技术生命周期（TLC）

**小节：** 6.1  
**关键概念：** TLC、跨越裂谷、保龄球道、龙卷风、大道、完整产品、保龄球棒方法

技术生命周期引自Geoffrey A. Moore与其Chasm Group的教材。当制定业务计划时，技术生命周期是团队要考虑的另外一个维度。

关键概念：

- **早期市场：** 由技术热衷者和幻想家组成
- **跨越裂谷：** 必须开发一套完整的产品来满足特定需求，要有令客户信服的购买理由
- **保龄球道：** 让邻近的客户接受产品，利用在一个客户群体上的成功来推进
- **龙卷风：** 产品变得全面集成和便宜，开始吸引主流市场
- **大道：** 运作优化成为关注重点

在生命周期的不同阶段，价值会有区别，影响着产品线的业务策略：

| 阶段 | 价值焦点 |
|------|----------|
| 早期市场 | 产品领袖，技术领先、特性、好处、质量、结成伙伴 |
| 保龄球道 | 客户亲密关系，产品质量、支持、热线服务、可靠性 |
| 龙卷风和大道 | 运作优化，覆盖范围、最低成本拥有、本地渠道、培训、最低价格、基于标准 |

市场管理流程与保龄球棒方法的衔接：

1. 确定潜在的细分市场（对应MM第2步：进行市场细分）
2. 评定各候选细分市场的级别（对应MM第3步：进行组合分析）
3. 制定保龄球棒模型与策略说明（对应MM第4步：制定业务策略与计划）
4. 通过调研来验证和量化

### MM-039 利润区与业务设计

**小节：** 6.1  
**关键概念：** 利润区、业务设计、五个领域、22种利润模型、价值链、客户优先需求、战略控制

利润区的主要概念是采用以客户为中心的业务设计。客户优先需求非常重要，客户甚至愿意为此付费，当无法满足时可能更换供应商。

业务设计五个领域：

1. **客户选择和价值定位：** 针对高价值客户机会提供独特的差异化客户提议
2. **价值获取/利润模型：** 利用何种利润模型从客户获取价值
3. **差异/战略控制：** 如何把可持续性嵌入到业务设计中
4. **范围：** 对活动和资产的范围要求
5. **组织体系：** 能最好支持业务设计的组织体系

22种利润模型包括：客户发掘模型、产品金字塔模型、多部件利润模型、配电盘模型、速度利润模型、卖座大片模型、利润倍增模型、创业式利润模型、专业化利润模型、基础产品模型、行业标准模型、品牌模型、独特产品模型、地区领先模型、大额交易模型、价值链定位模型、周期性利润模型、售后利润模型、新产品利润模型、相对市场份额利润模型、经验曲线型利润模型、低成本业务设计利润模型。

价值链选项：

- 降低成本或提高价值
- 通过自己的活动或通过其他方的活动
- 成本/价值 × 自己/竞争对手 = 四种组合

### MM-040 制定业务策略的12步骤分析

**小节：** 6.1  
**关键概念：** 12步骤分析、收入目标、现有/新细分市场、SPAN地位、$APPEALS差距、安索夫矩阵、收入缺口

整个分析可以分为12个步骤：

1. 确定3年收入目标（按当前方向与速度 vs 按最初目的目标）
2. 审视作为分析目标的细分市场
3. 确定哪些细分市场是现有的哪些是新的（测试：需要多长时间让别人了解你的独特竞争能力）
4. 对于现有细分市场——确定产品包映射、分析SPAN地位、分析$APPEALS差距
5. 对于现有细分市场——确定预计收入、效率行动、收入和利润趋势、主要行动
6. 对于现有细分市场——列出安索夫市场渗透象限的收入并计算总和
7. 现有细分市场检查点——检查收入缺口是否已关闭
8. 对于新细分市场——确定新细分市场、分析SPAN地位、分析$APPEALS差距
9. 对于新细分市场——确定预计收入、收入与利润趋势、主要行动、安索夫市场开发象限收入
10. 新细分市场检查点——检查收入缺口是否已关闭
11. 对新产品——确定潜在新产品包、与细分市场映射、确定预计收入
12. 新产品检查点——检查收入缺口是否已关闭

### MM-041 制定战略意图——分细分市场四步骤

**小节：** 6.2  
**关键概念：** 战略意图、准备性指示、价值陈述、七要素、三种策略、成本领导者、差异化、专注客户

制定战略包括四个步骤：

**第1步：归档并评估准备性指示** —— 准备性指示包括：收入差距/市场份额目标、重要市场驱动要素、分细分市场的SWOT分析、业务设计评审、Ansoff矩阵定位、SPAN分析、技术生命周期、利润区、客户$APPEALS的差距和关键优先级。归档后针对每个目标细分市场要采取哪些行动进行头脑风暴。

**第2步：制定战略意图陈述** —— 针对每个细分市场描述产品线计划怎样通过向目标客户提供特别的价值取得最佳业绩。战略意图陈述不应超过60个字或10点，直截了当描述关键目标、活动和时间。主题包括：产品/产品包/解决方案、创新或转型、渠道或伙伴建设、竞争地位、内部变化。

**第3步：为每个细分市场制定价值陈述** —— 回答客户为什么从公司购买东西。价值陈述包含七个关键要素：目标客户、需求、产品/产品包名称、类别、主要优势、主要竞争对手产品、主要差异化优势。定位方法：特性定位、优点定位、使用/应用定位、用户定位、竞争对手定位、品类定位、质量/价格定位。

**第4步：根据业务计划要素制定细分市场策略** —— 策略就是实现产品线目标所要做的正确的事情。三种成功的策略：成本领导者、产品包差异化优势、专注于客户的营销。

### MM-042 业务计划要素策略与风险评估

**小节：** 6.2  
**关键概念：** 业务计划要素、产品包、定价/条款、分销、IMC、支持、订单履行、风险评估、市场风险、技术风险、财务风险

六个业务计划要素的策略制定活动：

| 要素 | 策略内容 |
|------|----------|
| **1. 产品包** | 延伸、包装、性能、质量、整合、杠杆或合并、竞争迁移及新技术 |
| **2. 定价/条款** | 财务、保修、促销、推广、条款、定价和拥有的全部成本 |
| **3. 分销** | 范围、渠道、OEM、销售队伍、集成和主要客户 |
| **4. 综合市场宣传(IMC)** | 品牌价值、定位、广告、市场宣传、促销和证据点 |
| **5. 支持** | 客户支持、技术支持、协议、特殊培训、服务级别和销售计划资源 |
| **6. 订单履行** | 可获得性、交付模式、库存水平、退回的产品和升级 |

风险评估：

- **市场风险：** 影响产品包被市场接受的情况或影响整个市场规模
- **技术风险：** 影响所确定的技术性能或影响产品的及时可获得性
- **财务风险：** 影响产品的经常成本和利润率或影响开发费用和投资回报时间

风险等级：发生可能性超过25%为高风险；10%-25%为中等风险；低于10%为低风险。

## 7.0 跨产品线融合和优化业务计划

### MM-043 跨产品线融合和优化业务计划——概述

**小节：** 7.0  
**关键概念：** 跨产品线融合、投资组合、预算、IRB、产品包路标、两个层面

这一步骤包括整合、调整并优化所有源头计划，制定出投资组合，并根据经过优化的组合来制定预算。应在两个层面进行整合和优化：1）产品线层面；2）公司层面（IRB从整个公司层面进行整合）。

**目的：** 根据整合过的源计划作出一个经过优化的、能够实现产品线业绩目标的投资组合。

**角色：** 组合管理团队(PMT)和集成组合管理团队(IPMT)角色，包括事业部管理层角色。

**活动：**

- A. 在产品线内部整合并优化业务计划
- B. 跨产品线间整合并优化业务计划

**输出：** 根据整合、优化过的业务计划组合，已经承诺的业务计划和获得批准的预算和策略。整体产品包路标，满足每个产品线的市场机会以及跨产品线机会，并且匹配有合适的资源。

### MM-044 组合决策标准(PDC)——六步流程

**小节：** 7.1  
**关键概念：** PDC、安索夫产品模型、优先级排序、依赖关系、产品包路标、买进、持有、观望、卖掉

PDC是根据一致确定的决策标准对不同产品包进行优先级划分的一种方法，包括六个步骤：

**第1步：确定优先级排序框架**

- 明确分类模型：使用安索夫产品模型（市场成熟度 × 产品包成熟度）将产品包分为四类
- 确定评估属性和要素：市场吸引力（市场规模、竞争强度、增长情况、战略价值）、竞争地位（市场份额、产品优势、品牌优势、成本结构）、财务（开发费用、增加的PTI、现金流贡献）
- 为每个要素分配权重

**第2步：** 确定所有可能的项目——列出所有产品线业务计划中建议的产品包（新的和老的）

**第3步：** 将项目分成不同群组——根据安索夫分类：第1类市场渗透/扩展、第2类产品开发、第3类市场培育、第4类多样化

**第4步：** 根据优先级排序框架给产品包评级——使用高-中-低标准，通过研讨会排序，输入PDC模型获得得分

**第5步：** 明确项目之间的依赖关系——只确定技术依赖性

**第6步：** 在路标内对项目进行排序——根据PDC得分和依赖关系得分，制定截止线，画出产品包路标

四类结果：

| 结果 | 含义 |
|------|------|
| 买进 | 投资并作为重点 |
| 持有 | 继续投资并监控 |
| 观望 | 下期不考虑 |
| 卖掉 | 不考虑并解决 |

### MM-045 跨产品线融合与优化

**小节：** 7.2  
**关键概念：** 跨产品线、IRB、资源分配、情景分析、跨产品线产品包

这一流程步骤是确保在公司层面的资源协调整合。重点是确保针对不同产品线对资源进行最佳分配，以为公司产生最佳结果。另一个重点是确保跨产品线的问题/机会相应得到解决。

IRB是该步骤的关键角色，因为它是在跨不同产品线之间分配资源的决策主体。IPMT角色为向其产品线分配资源阐述理由，协助IRB进行决策。

活动：

- 每个产品线制定完PDC排序和路标后，如需更多资源，向IRB请求追加资源及原由
- IRB收到并评审完所有产品包路标后，从全公司进度进行排序
- IRB确认PDC模型中的评估要素及其权重
- 排序完成后制定出整体的产品包优先级排序清单
- 根据跨产品线不同产品包的排序情况决定如何分配资源
- 通过汇总每个产品线的组合，IRB对整个组合和预计业绩有完整统一了解
- 可进行情景分析确定重新分配资源的不同结果
- IRB确保跨产品线产品包的责任落实和资源匹配

## 8.0 管理业务计划，评估绩效

### MM-046 管理业务计划并评估绩效——概述

**关键概念：** 管理业务计划、PDT、IPD流程、任务书、纠正措施、流程评估

这一步包括执行业务计划，以及把产品线业务作为一个组合来积极管理。根据产品包路标上建议的时间，为所提议的不同产品包制定任务书。根据任务书成立产品开发团队（PDT），PDT将根据IPD流程进行产品开发。包括对业务计划实施结果的衡量和评估，以及制定任何需要的纠正措施。

### MM-047 管理业务计划——IO/SBP与任务书

**小节：** 8.1  
**关键概念：** IO/SBP、任务书、任务书背景材料、DCP、CDCP、PDCP、ADCP、GA、IPD流程

当到该启动一个产品包/解决方案的时间时，PMT应准备IO/SBP、任务书背景材料和任务书。

**IO/SBP（初始产品包/解决方案业务计划）包括以下章节：**

1. **概述** —— 对整个报告的概述，可用来制定任务书
2. **了解市场** —— 描述目标细分市场、环境因素、客户欲望和需要、竞争对手信息
3. **整体产品包/解决方案策略** —— 产品包/解决方案在组合中的位置和投资原因
4. **产品包概述** —— 宏观描述和主要需求
5. **财务评估** —— 收入、价格和毛利预测及敏感性分析
6. **项目进度和资源** —— 关键里程碑、假设前提、潜在PDT成员和人力需求
7. **风险评估和管理** —— 市场/客户风险、技术风险、财务风险、制造风险、采购风险、技术支援风险
8. **建议和替代方案** —— 向IPMT提交的建议方案

任务书背景材料有三个章节：组合分析、市场分析、建议的产品包。

任务书是2页的产品包/解决方案建议书的总结，向PDT指明方向。

按IPD流程，IO/SBP将变成PDT针对不同决策评审点（DCP）的O/SBP：

| 评审点 | 全称 |
|--------|------|
| CDCP | 概念决策评审 |
| PDCP | 计划决策评审 |
| ADCP | 可获得性决策评审 |
| GA | 一般可获得性 |

### MM-048 评估业务计划的实施情况

根据PLBP设定的目标来分析经营业绩，与生命周期管理流程有很强的关联。

**目的：** 确保PLBP制定的业务方向得以执行，如果需要的话确定纠正措施来帮助产品线实现业务目标。

**主要角色：** 组合管理团队（PMT）搜集生命周期信息并根据目标衡量业绩；IPMT审批纠正措施并提供支持和资源。

**活动：** 搜集组合中每个产品包/解决方案的财务信息（市场份额、产品收入、毛利等），对照组合模型中的预测来衡量实际业绩。如果需要采取纠正措施（加快或推迟产品开发项目、合并或分拆一个或多个R版本等），制定行动计划并获取IPMT批准。任何建议的更改通过IPD PCR流程提交给PDT。

### MM-049 评估流程效果和效率——TPM（变革进展衡量指标）

**小节：** 8.3  
**关键概念：** TPM、变革进展衡量、五种评估程度、试点、推行、功能级、集成、世界级、推行广度

使用IPD流程中使用的变革进展衡量指标（TPM），帮助找到必要的措施来提高MM流程的效果和效率。MM流程的TPM重点在两个领域：市场规划和组合分析。

五种评估程度：

| 程度 | 描述 |
|------|------|
| 1. 试点 | 受控引入，可能接受强有力的引导来测试和检验新流程 |
| 2. 推行 | 几个产品线进行推行，执行情况不均衡不协调 |
| 3. 功能级 | 大部分产品线都在推行，执行方面有所改进，行为方式开始转变 |
| 4. 集成 | 推行完成，执行质量得到很大提高，市场管理已经融入文化 |
| 5. 世界级 | MM衡量指标达到业界最佳，组织与不断发展的市场需要持续进行整合 |

TPM评估涵盖四个领域13个标准：

- **理解市场和进行市场细分**（3个标准：市场调研/市场数据库、细分市场分析、市场细分标准）
- **进行组合分析制定业务战略与计划**（6个标准：使用方法、业务单位组合、财务分析、分析工具、业务计划、决策标准）
- **管理业务计划并评估效果**（4个标准：度量系统、责任人、细分市场/验收、关联）

推行广度：试点(>20%) → 推行(>20%) → 功能级(>60%) → 集成(>80%) → 世界级(100%)

### MM-050 参考产品包/解决方案营销战略

**小节：** 9.1  
**关键概念：** 产品包营销战略、差异化特性、价值陈述、卖点、主要产品包、标准产品包、非核心产品包

产品包/解决方案营销战略关注两个主要问题：通过产品包和客户形成需求。单个产品包/解决方案战略必须与整个产品线战略保持一致并从属于产品线战略。

战略性考虑因素：

- 产品包/解决方案系列及差异化特性
- 通过所选销售渠道提供的产品包/解决方案系列
- 各产品包/解决方案的价值陈述
- 产品包/解决方案开发标准和计划

制定方法：

1. 定义产品包（主要销售渠道、主要产品、主要服务、定价基础、独特卖点）
2. 定义基本产品包/解决方案系列（主要产品包、标准产品包、非核心产品包）
3. 定义产品包/解决方案特性
4. 确定与竞争对手相比的卖点（产品包、产品和服务、特性三个层次）
5. 根据客户类型提供不同的产品包/解决方案
6. 详细说明产品包/解决方案开发标准和计划

不制定战略的影响：缺乏对产品包长远走向的了解、没有明确的路标、无法根据组合中其他产品包考虑该战略、缺乏清晰的定位。

### MM-051 参考定价战略

**小节：** 9.2  
**关键概念：** 定价战略、价值定价、竞争定价、直觉定价、通行定价、渗透定价、监控定价、多维定价

定价战略给团队提供了一个做出最合适的产品包定价决策的结构。定价是营销组合中唯一能够立刻影响收入的要素。

战略性考虑因素：市场细分、产品包期望的定位、分销渠道、区域、竞争者、产品包内在本质、价格敏感性、增加到基本产品包中的价值。

制定方法：

1. **设定目标：** 明确产品线目标（收入、单位产量、利润、进入新市场、抵御竞争对手）
2. **多维的定价方法：**

| 方法 | 描述 |
|------|------|
| 价值定价 | 不同细分市场的产品包价值不同 |
| 竞争和对比定价 | 跟从其他企业的价格 |
| 直觉定价 | 凭直觉作出定价决策（应尽力避免） |
| 通行定价 | 根据各细分市场愿意支付的最高价格来区分 |
| 渗透定价 | 进入新市场时采用低价，地位巩固后提高 |
| 控制或监控定价 | 政府控制或受准政府实体监控 |

3. **确定价格的步骤：** 决策销售组合问题→确定定价目标→估计需求→测试价格点→成本预计→分析竞争对手价格→选择定价方法→选择产品包价格→监控结果

4. **定价战略问题：** 全球业务运作、特殊促销活动、客户细分市场区别定价、竞争定价含义

5. **趋势和未来情形设想**

### MM-052 参考营销渠道战略

**小节：** 9.3  
**关键概念：** 渠道战略、购买者行为、渠道冲突、渠道经济、渠道控制、纵向联合、横向联合

通过营销渠道交付价值给用户——价格合理、易于获取、始终如一。现代分销渠道是以购买者感受为驱动的复杂体系。

制定渠道战略的活动：

- 确定客户对渠道的偏好
- 确定渠道的优势和劣势
- 估计跨渠道的支持
- 确定最佳解决方案的渠道
- 评估渠道冲突
- 计算每个渠道的投资成本和收益
- 创建评估不同渠道表现的方法
- 制定计划说服客户迁移到最佳渠道

战略制定方法：

1. **考虑购买者行为：** 客户为什么使用这些渠道？他们为什么忠于这个渠道？
2. **评估渠道的强弱势：** 与公司目标客户需求一致性、公司优势与渠道优势一致性
3. **考虑渠道宣传：** 渠道的价值在于成员分享的信息
4. **了解渠道冲突：** 渠道冲突是好的现象，表示公司正努力提高市场地位
5. **分析渠道经济：** 各渠道收入、业务成本、投资回报
6. **考虑渠道控制：** 纵向（直接控制）和横向（授权给渠道伙伴）

### MM-053 参考市场宣传策略

**小节：** 9.4  
**关键概念：** 市场宣传策略、IMC、营销目的、目标对象、信息制定、渠道和形式、衡量标准、线上、线下

市场宣传策略为跨专业领域、渠道和方式集成并统一地传达信息提供了框架。综合市场宣传工作能产生较大的说服力，因为它能带来的增效作用。

策略考虑要素：

1. **营销目的：** 确定宣称活动的目的和期望的行动
2. **目标对象：** 确定某宣称活动的目标对象
3. **信息制定：** 考虑每个目标对象需要知道什么信息才能被说服
4. **渠道和形式：** 考虑什么传递渠道和方式能使信息产生最佳效果
5. **执行：** 利用计划执行战术概要和时间安排
6. **衡量标准：** 确定计划中每个目标的成功标准

制定方法：

1. 确定营销目标（细分市场、行动要求、关键成功要素）
2. 确定要宣传的信息
3. 确定需要将信息宣传给谁
4. 决定传递信息的方式和渠道（线上：广告、广告牌、销售点宣传；线下：直接邮寄、在线、公关、促销）
5. 针对衡量标准对成功进行衡量（销量增加、获取新客户/市场份额、直接邮寄反应、网站浏览量增加、客户满意度提高、竞争对手反应、媒体覆盖率、品牌意识提高等）
