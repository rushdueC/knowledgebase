1.0市场管理流程六个步骤概述
MM-001

市场管理的定义与价值实现六个领域

1.0
市场管理是一种系统的方法，用于对广泛的机会进行选择收缩，制定出一套以市场为中心的、能够带来最佳业务成果的战略与计划。市场管理在协调价值实现的六个领域起着非常重要的作用，这六个领域是：选择价值、创造价值、提取价值、宣传价值、交付价值和理解价值。 市场管理流程的目的是为公司所有产品线、产品族及产品营销计划实现价值创造提供一致的分析，使公司能够通过明智的投资创造最大的价值。 六个价值领域： ①选择价值：市场管理活动为战略及产品线规划，非营销活动为财务和战略 ②创造价值：市场管理活动为产品包管理和产品线管理，非营销活动为开发 ③提取价值：市场管理活动为产品包管理和产品线管理，非营销活动为财务 ④宣传价值：市场管理活动为渠道启动和产品线管理，非营销活动为宣传和销售与技术支援渠道 ⑤交付价值：市场管理活动为渠道启动和产品线管理，非营销活动为销售与技术支援渠道 ⑥理解价值：市场管理活动为战略及产品线规划，非营销活动为财务和战略
价值实现六个领域选择价值创造价值提取价值宣传价值交付价值理解价值协调价值实现活动
MM-002

市场管理流程的本质——业务流程

1.0
市场管理规划的目的是为整个公司的价值创造活动提供一致的分析。核心问题包括：公司的投资如何分配到各产品线是最明智的？公司将如何作出决策？ 市场管理流程是一道业务流程，它运用严格、规范的方法对市场走势及业务要求及需求进行分析，创建合理的市场细分规则，对要投资和取得领先地位的细分市场进行选择和优先级排序，从而制定可执行的业务计划。
投资分配决策业务流程市场细分规则优先级排序可执行业务计划
MM-005

市场管理流程六个主要步骤

1.1
市场管理流程活动可分成以下六个主要步骤： 1. 了解市场 2. 进行市场细分 3. 进行组合分析 4. 制定业务战略和计划 5. 跨产品线融合和优化业务计划 6. 管理业务计划，评估绩效 流程目的：通过该流程，及时、有效地将市场需求转化为领先的产品包/解决方案，满足或超出客户期望。
六步骤了解市场市场细分组合分析业务战略和计划跨产品线融合评估绩效
MM-010

业务计划框架

1.5
业务计划架构由互为补充的七个部分组成： 核心要素：产品包、定价/条款、分销、综合营销宣传 运营要素：支持/技能、履行 评估要素：绩效评估与风险评估 支持三种结构类似的业务计划：产品线业务计划(PLBP)、细分市场业务计划(SBP)、产品包/解决方案业务计划(O/SBP)。 组织与业务计划的融合：公司→业务部业务计划、产品线→产品线业务计划、细分市场→细分市场业务计划、产品包/解决方案→产品包/解决方案业务计划
业务计划框架七个部分PLBPSBPO/SBP核心要素运营要素评估要素
MM-011

三种业务计划的使用

1.6
1. 产品线业务计划（PLBP）：记录产品线所参与的市场情况，在产品线内优化计划组合，确保组合满足或超过产品线的绩效目标。 2. 细分市场业务计划（SBP）：跨多个产品线的细分市场的业务计划，用于记录能够驱动细分市场中业绩的战略、计划和主要产品包/解决方案。 3. 产品包/解决方案业务计划（O/SBP）：完成分两个阶段——初始产品包/解决方案业务计划（IO/SBP）和最终产品包/解决方案业务计划。IO/SBP形成于市场管理流程，通过IPMT审批，在IPD流程中由PDT最终定稿。一旦IO/SBP审批通过，便组建PDT，开始最终O/SBP的工作。
PLBPSBPO/SBPIO/SBPPDTIPD流程
2.0市场管理流程角色
MM-013

市场管理流程角色概述

2.0
角色定义了市场管理流程中的角色，不是描述营销职业生涯中的职业、岗位或头衔，而是描述流程所定义的角色。角色应该由内部或外部掌握有营销技能的合格个体来执行。 主要角色： 1. 集成组合管理团队（IPMT）角色 2. 市场管理协调员（MMC）角色 3. 市场分析（MA）角色 4. 财务分析（FA）角色 5. 组合管理团队（PMT）角色 流程角色并不等同于岗位头衔，任何受过正规培训的营销专业人员任何时间都能执行流程角色。
IPMTMMCMAFAPMT角色与岗位的区别
MM-014

集成组合管理团队（IPMT）角色

2.0
IPMT角色负责产品线、细分市场或产品包/解决方案层次的产品包组合在全球的业绩。由代表全球硬件和软件开发、营销、销售、生产/订单履行、采购、财务和其他功能领域的高层人员组成。 核心职责：作出持续业务投资决策、开展审批和高层决策活动、通过正式的决策评审合理进行产品线组合、负责及时解决跨产品线项目问题、将营销和业务计划与产品包开发相融合、在IPD决策评审点分配资源给PDT、激励和管理PDT的绩效。
IPMT产品包组合投资决策IRBPDT管理
MM-017

市场分析（MA）角色的子角色

2.0
MA角色可进一步分为以下子角色： 1. 竞争性/竞争对手分析和市场情报 2. 市场细分 3. 市场需求（管理市场调研项目，执行需求管理流程5个步骤中的前3个） 4. 客户情报分析 5. 销售渠道/业务伙伴 6. 解决方案开发 7. 联盟发展 8. 计划员（规划产品系统管理需求） 9. 技术（技术需求和新技术） MA角色负责调查和分析产品包、竞争、经济/人口和市场调研的数据，向IPMT和PMT提供支撑和建议。
MA竞争分析市场细分市场需求客户情报联盟发展
MM-018

组合管理团队（PMT）角色

2.0
PMT角色负责定义所选细分市场的市场细分架构，确定组合模型的标准和权重，使用组合分析数据对子细分市场进行优先排序，负责制定业务战略和计划。 3类资源执行PMT角色： 1. 营销副总裁——制定集团或范畴的战略计划 2. 营销副总裁或营销经理——制定产品线和/或细分市场的战略计划 3. 营销经理——制定具体产品包/解决方案的战略计划 在各步骤中的参与：步骤1（了解市场）竞争分析和市场需求角色起重要作用；步骤2（进行市场细分）由市场细分角色完成；其余步骤所有MA和FA角色参与。
PMT市场细分架构组合模型优先排序三类资源
3.0理解市场
MM-019

理解市场——概述

3.0
这一步骤用于对市场进行概要描述，包括了解和评估市场的经济、行业、竞争对手、客户和产品线机会。 目的：促进IPMT加强对自己所运作的环境的了解，并对该环境进行明确描述，有助于产品线细分市场并进行优先排序。 主要角色：IPMT（定义愿景、使命和目标）；MA（第二重要角色，进行市场环境分析）；MMC。 活动：A. 定义和整合使命和目标（IPMT）；B. 进行市场分析（MA） 输出：归档的产品线愿景、使命和目标；市场评估文档。 使能器：宏观环境分析、竞争分析、公司自身分析、市场分析、SWOT分析、市场地图、业务设计
理解市场PL-IPMT市场评估文档使命与目标环境分析
MM-021

进行市场分析——四个分析维度

3.2
市场评估包含四个分析维度： 1. 环境分析：政治、经济、社会、技术 2. 竞争分析：了解主要竞争对手，确定能力和意图，可使用波特五种力量模型（供应商议价能力、现存公司间竞争、购买者议价能力、新入行者威胁、替代产品威胁） 3. 公司自身分析：关注4个方面——本年度和三年目标、财务状况、产品生命周期(PLC)、组合 4. 市场分析：确定市场驱动力和主要趋势，关注市场规模、增长、特点、客户细分需求、购买者行为、中介和价值网
环境分析竞争分析波特五力模型公司自身分析市场分析PLC
MM-024

市场地图

3.2
根据对竞争市场的分析和了解，团队描绘出市场上产品的流动情况——即市场地图。记录了在定义市场上作出购买决策的所有重要阶段。 市场地图定义了市场动力、制造商与最终用户间的价值链，考虑了各种购买机制，包括与分销渠道和影响者有关的部分。重点突出了直接销售和通过渠道分销的产品量和价值，指出拓展市场的潜在机会。
市场地图价值链购买机制分销渠道
MM-025

业务设计评估

3.2
业务设计关注四个领域： 1. 客户选择和价值定位：可以为哪些客户增加实际价值并可以盈利？ 2. 价值获取/利润模型：如何获取所创造的一部分价值作为利润？ 3. 差异/战略控制：客户为什么购买？价值陈述与竞争对手的差异？战略控制点是什么？ 4. 范围：要卖什么产品、服务和解决方案？哪些活动自己执行，哪些与合作伙伴执行？ 组织体系：什么样的组织体系能提供最好的支持？
业务设计客户选择利润模型战略控制点范围
4.0进行市场细分
MM-026

进行市场细分——概述

4.0
确定结构来进一步分析市场、收集信息，对机会进行排序和选择。产品线必须使用一致的细分变量和评估标准。 所定义的细分市场必须满足：独特性、重要性、可衡量性、持久性和可识别性要求。 输出：批准的市场细分框架、初步选定的细分市场、每个所选细分市场的概貌、初始客户$APPEALS分析、公司和竞争对手产品与每个细分市场映射。
市场细分独特性重要性可衡量性持久性可识别性$APPEALS
MM-028

市场细分流程七步骤

4.1
第1步：审视市场细分框架——从公司高层获得指导，预期80:20的Pareto效果 第2步：确定谁购买——建议数量控制在最多10个以内 第3步：确定买什么——列出所有重要产品/产品包，找出10-15种模式 第4步：确定谁买什么——将每个谁与真正重要的买什么组合，减少到12-15个最有吸引力的初步细分市场 第5步：判断为什么购买——分析客户行为，关注基于需要的好处 第6步：确定主要细分市场——描述并解释对大约10个细分市场的选择原因 第7步：测试可行性——验证独特性、重要性、可衡量性、持久性和可识别性
七步骤Pareto效果微型细分市场好处分类可行性测试
MM-029

客户$APPEALS框架

4.2
$APPEALS是八类购买标准的缩略语： $ - 价格 (Dollars) A - 可获得性 (Availability) P - 包装 (Packaging) P - 性能 (Performance) E - 易用性 (Ease of Use) A - 保证 (Assurances) L - 生命周期成本 (Life Cycle Cost) S - 社会接受程度 (Social Acceptance) $APPEALS框架能够使团队：处理目标细分市场的全部客户欲望与需要；建立客户驱动的需求集；确定主要分界标准；确定促使客户选择产品包的主要差异。
$APPEALS价格可获得性包装性能易用性保证生命周期成本社会接受程度
5.0进行组合分析
MM-031

SPAN四种宏观战略态势

5.1
可用两个维度评估每个细分市场：市场吸引力和竞争地位。 1. 增长/投资：细分市场有吸引力且有很强竞争优势。应扩大分销、扩大生产投资、继续研发投资、加大营销。 2. 获取技能：有吸引力但竞争优势较弱。应限制分销覆盖面、对生产研发和人力投资、积极定价促销以获得市场份额。 3. 收获/重新划分：没有吸引力但有很强竞争优势。应维持现有分销、重点运作效率、限制营销活动、研发重点放在降低成本。 4. 避免/退出：没有吸引力且竞争优势较弱。应逐渐撤销分销、大力削减成本、减少或停止产能和研发费用。
SPAN增长/投资获取技能收获/重新细分避免/退出市场吸引力竞争地位
MM-032

SPAN市场吸引力评估要素

5.1
四个要素评估市场吸引力： 1. 市场规模：反映相对收入机会 2. 市场增长率：以后三年的年度复合增长率(CAGR) 3. 利润潜力：三个子要素——直接/间接竞争、进入威胁、客户/供应商压力 4. 战略价值：对产品线和整个公司的战略价值/重要性 权重系数之和为100。高、中、低评分转换为5、3、1分数后乘以权重系数，得到市场吸引力得分。
市场吸引力市场规模增长率利润潜力战略价值权重系数
MM-035

财务分析（FAN）

5.1
FAN对比每个细分市场的预期收益比例和累计收入： 收益比例：内部收益率(IRR)是税前利润(PTI)或现金流与产品包的比率。 累计收入：基于每个产品包收入的预期收入，可衡量运营现金流出。 SPAN和FAN相辅相成： - FAN回答：是否在所服务的细分市场赚钱？回报是否超过资本成本？ - SPAN回答：该细分市场的吸引力有多大？产品包定位得怎么样？ 当前的SPAN和FAN地位可用来作为基线，预测战略行动的结果。
FANIRRPTI累计收入最低投资回报率基线预测
6.0制定业务策略和计划
MM-037

安索夫矩阵

6.1
安索夫矩阵通过评估增长策略选择，为支持目标提供框架。两个维度：市场/细分市场的新旧和产品/技术的新旧。 四类营销目标： 1. 市场渗透：现有市场上出售现有产品（快速、低风险、低成本） 2. 市场开发：将现有产品卖到新市场（较缓慢、风险较大） 3. 产品开发：向现有市场出售新产品（研发投入） 4. 多样化：向新市场出售新产品（高风险、昂贵） 缺口分析两个方面：运作缺口（改进效率和市场渗透）、新策略上的缺口（市场开发、产品开发和多样化）。
安索夫矩阵市场渗透市场开发产品开发多样化缺口分析
MM-038

技术生命周期（TLC）

6.1
引自Geoffrey A. Moore的教材。关键概念： - 早期市场：技术热衷者和幻想家 - 跨越裂谷：必须开发完整产品来满足特定需求 - 保龄球道：让邻近的客户接受产品，利用成功来推进 - 龙卷风：产品全面集成和便宜，吸引主流市场 - 大道：运作优化成为关注重点 在生命周期不同阶段，价值有区别，影响策略： - 早期市场：技术领先、特性、好处、质量 - 保龄球道：客户亲密关系、质量、支持、可靠性 - 龙卷风和大道：运作优化、最低成本、本地渠道、最低价格
TLC跨越裂谷保龄球道龙卷风大道完整产品
MM-039

利润区与业务设计

6.1
利润区采用以客户为中心的业务设计。业务设计五个领域： 1. 客户选择和价值定位 2. 价值获取/利润模型 3. 差异/战略控制 4. 范围 5. 组织体系 22种利润模型包括：客户发掘模型、产品金字塔模型、多部件利润模型、配电盘模型、速度利润模型、卖座大片模型、利润倍增模型、创业式利润模型、专业化利润模型、基础产品模型、行业标准模型、品牌模型、独特产品模型、地区领先模型、大额交易模型、价值链定位模型、周期性利润模型、售后利润模型、新产品利润模型、相对市场份额利润模型、经验曲线型利润模型、低成本业务设计利润模型。
利润区业务设计五个领域22种利润模型价值链战略控制
MM-041

制定战略意图——四步骤

6.2

组合决策标准(PDC)——六步流程

7.1
PDC是根据一致确定的决策标准对不同产品包进行优先级划分的方法： 第1步：确定优先级排序框架——安索夫产品模型分类、确定评估属性（市场吸引力、竞争地位、财务）、分配权重 第2步：确定所有可能的项目——列出所有建议的产品包（新的和老的） 第3步：将项目分成不同群组——市场渗透/扩展、产品开发、市场培育、多样化 第4步：给产品包评级——使用高-中-低标准，输入PDC模型获得得分 第5步：明确依赖关系——只确定技术依赖性 第6步：在路标内排序——制定截止线，画出产品包路标 四类结果：买进、持有、观望、卖掉

IO/SBP与任务书

8.1
IO/SBP（初始产品包/解决方案业务计划）包括8个章节：概述、了解市场、整体产品包/解决方案策略、产品包概述、财务评估、项目进度和资源、风险评估和管理、建议和替代方案。 任务书背景材料有3个章节：组合分析、市场分析、建议的产品包。 任务书是2页的总结，向PDT指明方向。 按IPD流程，IO/SBP将变成PDT针对不同决策评审点(DCP)的O/SBP：CDCP（概念决策评审）、PDCP（计划决策评审）、ADCP（可获得性决策评审）、GA（一般可获得性）。

MM-049

TPM——变革进展衡量指标

8.3
使用变革进展衡量指标(TPM)帮助找到提高MM流程效果和效率的措施。TPM重点在两个领域：市场规划和组合分析。 五种评估程度： 1. 试点：受控引入，测试和检验新流程 2. 推行：几个产品线进行推行，执行不均衡 3. 功能级：大部分产品线在推行，行为方式开始转变 4. 集成：推行完成，市场管理融入文化 5. 世界级：MM衡量指标达到业界最佳 推行广度：试点(>20%) → 推行(>20%) → 功能级(>60%) → 集成(>80%) → 世界级(100%)

MM-051

定价战略

9.2
定价是营销组合中唯一能立刻影响收入的要素。六种定价方法： 1. 价值定价：不同细分市场价值不同 2. 竞争和对比定价：跟从其他企业价格 3. 直觉定价：凭直觉定价（应避免） 4. 通行定价：按各细分市场愿意支付的最高价格区分 5. 渗透定价：进入新市场时低价，地位巩固后提高 6. 控制或监控定价：政府控制或监控 确定价格的步骤：决策销售组合→确定定价目标→估计需求→测试价格点→成本预计→分析竞争对手价格→选择定价方法→选择产品包价格→监控结果
