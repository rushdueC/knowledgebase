# 战略地图：把战略画成一条因果链

> 适用：战略沟通、战略解码、BSC 落地、董事会汇报
> 关键词：战略地图、战略主题、因果链、无形资产、战略准备度、平衡计分卡

## 1. 什么是战略地图

战略地图（Strategy Map）由卡普兰与诺顿在 2004 年同名著作中系统提出，是平衡计分卡的"前置图"：**计分卡告诉你量什么，地图告诉你为什么量这些**。

它的本质是一张**因果假设图**：

> 如果我们在【学习与成长】上投入 A，
> 那么【内部流程】B 会改善，
> 于是【客户】C 会提升，
> 最终【财务】D 会实现。

一张合格的战略地图，任何一条箭头都能用"因为…所以…"读通；读不通的箭头，就是战略没想清楚的地方。

## 2. 标准四层面结构

```
┌─────────────────────────────────────────────────────────────┐
│ 财务层面： productivity 战略        │        增长战略        │
│  · 改善成本结构  · 提高资产利用率   │  · 拓展收入机会 · 提升客户价值 │
├─────────────────────────────────────────────────────────────┤
│ 客户层面： 价值主张（四选一/组合）                            │
│  成本领先 │ 产品领先 │ 客户亲密 │ 系统锁定                    │
│  价格 质量 可用性 选择 功能 服务 关系 品牌                    │
├─────────────────────────────────────────────────────────────┤
│ 内部流程层面： 四大流程集群                                   │
│  运营管理 │ 客户管理 │ 创新 │ 法规与社会                      │
├─────────────────────────────────────────────────────────────┤
│ 学习与成长层面： 三类无形资产                                 │
│  人力资本（技能/人才）│ 信息资本（系统/数据）│ 组织资本（文化/领导力/协同）│
└─────────────────────────────────────────────────────────────┘
```

### 2.1 财务层面的两个战略

- **生产力战略**：把同样的产出用更少资源做出来（成本结构改善、资产利用率提升）；
- **增长战略**：把同样的资源卖出更多价值（新收入来源、客户价值提升）。

这两个战略对应不同的时间尺度：生产力见效快，增长见效慢。地图要显示二者的平衡。

### 2.2 客户层面的价值主张

客户层面是战略的"心脏"。企业必须明确选择一种主导价值主张，否则资源会被拉向四个方向：

| 价值主张 | 核心承诺 | 对应内部流程重点 |
|---|---|---|
| 成本领先 | 同等质量下最便宜 | 运营管理流程 |
| 产品领先 | 最早、最好、最先进 | 创新流程 |
| 客户亲密 | 最懂我、最省心 | 客户管理流程 |
| 系统锁定 | 换掉我成本太高 | 客户管理 + 创新（生态） |

### 2.3 内部流程的四个集群

| 集群 | 覆盖活动 | 关键指标 |
|---|---|---|
| 运营管理 | 采购、生产、分销、风险管理 | 成本、周期、质量、安全 |
| 客户管理 | 选择、获取、保留、增长 | 获客成本、留存、份额 |
| 创新 | 机会识别、研发、上市 | 新品收入占比、上市周期 |
| 法规与社会 | 合规、环保、社区、员工 | 违规次数、碳排放、社区评价 |

### 2.4 学习与成长的三种资本

- **人力资本**：战略所需的关键岗位、技能、胜任度；
- **信息资本**：支撑流程的系统、数据、网络；
- **组织资本**：文化、领导力、团队协同、变革能力。

对应的核心问题是"**战略准备度**"：这些无形资产的现状，距离战略要求还差多少？

## 3. 战略主题：地图的骨架

一张地图通常包含 4–6 个**战略主题**（strategic theme），每个主题是一条独立的纵向因果链。例如一家工业设备企业的四个主题：

1. **从卖设备到卖服务**（增长）
2. **交付周期缩短 40%**（生产力）
3. **关键客户深度经营**（客户亲密）
4. **供应链韧性建设**（风险）

每个主题有自己的目标、指标、预算、责任人。这样做的价值是：把一张复杂的大图拆成几个可以独立管理、独立问责的"战略项目"。

## 4. 因果链示例

### 4.1 制造业：从代工到自主品牌

| 层面 | 目标 | 因果解释 |
|---|---|---|
| 财务 | 自主品牌收入占比 40% | 品牌溢价带来毛利率提升 |
| 客户 | 目标客户品牌认知度 60% | 认知度提升 → 试用 → 复购 |
| 流程 | 新品上市周期 12 个月；直营渠道覆盖 50 城 | 快速上新支撑品牌新鲜度；直营渠道掌控体验 |
| 学习 | 引进 30 名品牌与渠道人才；建成用户数据平台 | 人才与数据是前两层的前提 |

读法：因为我们建成了用户数据平台并引进品牌人才（学习），所以能 12 个月上新并开出直营网点（流程），于是目标客户认知度提升（客户），最终自主品牌收入占比达到 40%（财务）。

### 4.2 银行业：提升零售客户经营

| 层面 | 目标 |
|---|---|
| 财务 | 零售 AUM 增长 25%，中间业务收入占比 30% |
| 客户 | 财富客户留存率 90%，NPS 45 |
| 流程 | 客户 360 视图上线；理财经理人均服务客户数提升 50%；产品上架周期 2 周 |
| 学习 | 理财经理认证通过率 85%；数据中台建成 |

### 4.3 SaaS 公司：降低流失率

| 层面 | 目标 |
|---|---|
| 财务 | 净收入留存率（NRR）115% |
| 客户 | 关键功能激活率 70%，客户健康分 > 80 |
| 流程 | 新客 30 天 onboarding 完成率 90%；产品迭代两周一次 |
| 学习 | 客户成功团队扩编；产品分析埋点体系完善 |

### 4.4 公立医院：提升服务质量

| 层面 | 目标 |
|---|---|
| 使命/社会 | 区域就诊率提升，患者满意度 90 |
| 服务对象 | 平均候诊时间 < 30 分钟，投诉率下降 50% |
| 内部流程 | 分诊准确率 95%，检查预约一次完成率 85% |
| 学习 | 护士分层培训覆盖率 100%，信息系统互联互通 |

## 5. 绘制战略地图的七个步骤

| 步骤 | 动作 | 产出 | 常见坑 |
|---|---|---|---|
| 1 | 明确战略与价值主张 | 一句话战略主张 | 战略还没定就画图 |
| 2 | 确定 4–6 个战略主题 | 主题清单 | 主题太多（>7 个） |
| 3 | 自上而下画财务与客户目标 | 上半张图 | 目标不可衡量 |
| 4 | 设计内部流程支撑 | 流程目标 | 流程与价值主张不匹配 |
| 5 | 识别所需无形资产 | 学习成长目标 | 写成培训计划 |
| 6 | 逐条画箭头并写因果解释 | 带注释的地图 | 箭头画了但说不清"因为所以" |
| 7 | 为每个节点配指标与责任人 | 地图 + 计分卡 | 有目标无指标 |

**质量检验三问**：
1. 每一个客户目标，是否都有至少一个流程目标支撑？
2. 每一个流程目标，是否都有对应的无形资产准备？
3. 从下往上读，能否用一段话讲通整张图？

## 6. 无形资产与战略准备度

战略地图最有价值的贡献之一，是把"人、系统、文化"这些软东西**接到财务结果上**。做法是三步：

1. **定义战略所需的无形资产**：不是"提升员工素质"，而是"培养 50 名能独立负责海外项目的项目经理"；
2. **评估现状与目标的差距**：用 0–100% 的准备度打分；
3. **确定投资优先级**：准备度最低、对战略影响最大的，优先投。

| 资产类别 | 战略所需 | 现状 | 准备度 | 投资动作 |
|---|---|---|---|---|
| 人力资本 | 50 名海外项目经理 | 18 名 | 36% | 内部选拔 + 外部招聘 + 轮岗 |
| 信息资本 | 全球项目管理系统 | 分散 Excel | 20% | 统一平台，分两期上线 |
| 组织资本 | 跨区域协同机制 | 各自为政 | 30% | 设立区域联席会 + 共享考核 |

## 7. 战略地图与 BSC 的关系

| | 战略地图 | 平衡计分卡 |
|---|---|---|
| 作用 | 讲清"为什么" | 明确"量什么" |
| 形式 | 图 + 因果链 | 表 + 指标 + 目标值 |
| 使用者 | 高层、全员沟通 | 管理者、考核部门 |
| 顺序 | 先画图 | 后设计指标 |

一句话：**地图是因，计分卡是果与度量**。没有地图的计分卡，是指标集合；没有计分卡的地图，是墙上的海报。

## 8. 公共部门与非营利组织的战略地图

公共部门要把"使命"放在最顶端，财务变成"预算与合规"放在底部或侧面：

```
使命（为什么存在）
  ↓
服务对象（谁受益、满意度）
  ↓
内部流程（哪些流程必须卓越）
  ↓
学习与成长（能力建设）
  ↓
预算与合规（资源与约束）
```

要点：
- 目标值要兼顾效率与公平，避免"唯指标论"；
- 引入外部评价（服务对象、第三方评估）；
- 明确"不可牺牲的底线"（安全、合规、伦理）。

## 9. 十个常见错误

1. 把地图画成组织架构图或流程图；
2. 四个层面各写各的，箭头随意连；
3. 战略主题超过 7 个，失去焦点；
4. 客户层面没选价值主张，四个都想要；
5. 内部流程只写运营，忽略创新与合规；
6. 学习成长写成"加强培训"；
7. 因果箭头无法用"因为…所以…"读通；
8. 目标没有基线值，无法判断进步；
9. 地图做完就挂墙上，不与预算、考核、会议联动；
10. 一年不更新，战略已变图未变。

## 10. 一页纸地图模板（文字版）

```
【战略主张】为______客户提供______价值，靠______能力取胜。

【主题一】______
  财务：______（指标/目标）
  客户：______（价值主张：成本/产品/亲密/锁定）
  流程：______（运营/客户/创新/合规）
  学习：______（人力/信息/组织）

【主题二】……
【主题三】……

【战略准备度】人力__% 信息__% 组织__%
【关键假设】1.____ 2.____ 3.____
【验证指标】1.____ 2.____ 3.____
```
