# 战略规划方法论总览：从洞察到执行的完整闭环

> 适用：企业战略部、经营分析岗、咨询顾问、商学院案例写作
> 关键词：战略管理闭环、DSTE、SP/BP、五看三定、战略洞察、规划文档结构

## 1. 什么是战略规划

战略规划不是"写一份未来五年的 PPT"，而是一套**在不确定环境下持续做出取舍并配置资源**的管理机制。它至少回答五个问题：

1. **我们在哪里**——外部环境与自身能力的客观诊断；
2. **我们要去哪里**——愿景、使命与 3–5 年的战略目标；
3. **我们凭什么赢**——价值主张、战略控制点与差异化来源；
4. **我们要做什么**——业务组合、关键任务与资源分配；
5. **我们怎么知道做对了**——衡量指标、复盘节奏与纠偏机制。

一个常见误解是把"战略"等同于"目标"。目标是结果，战略是**导致结果的一组因果假设**：因为客户结构正在从 A 转向 B，因为我们在 B 上有独特能力，所以把资源投向 B，就能在三年内取得 C。战略规划的价值在于把这组假设写清楚、检验它、并据此下注。

另一个误解是把战略规划等同于年度预算。预算回答"钱怎么花"，战略回答"为什么是这件事而不是那件事"。二者混同，就会出现"预算做得精细、战略却没人记得"的局面。

## 2. 战略的四个层级

| 层级 | 核心问题 | 典型输出 | 决策者 |
|---|---|---|---|
| 集团/公司战略 | 进入哪些业务？如何配置资本？ | 业务组合、并购与退出、集团能力建设 | 董事会、CEO |
| 业务战略（SBU） | 在选定战场如何取胜？ | 客户选择、价值主张、竞争策略 | 事业部总经理 |
| 职能战略 | 如何支撑业务战略？ | 人才、研发、供应链、数字化、品牌 | 职能负责人 |
| 个人/团队目标 | 我今年必须做成什么？ | PBC、OKR、关键任务清单 | 各级管理者 |

四层之间必须"一条线穿到底"：集团战略里的一句话，要能翻译成事业部的关键任务，再翻译成个人的考核项。断了任何一层，战略都会停在会议室。

## 3. 战略管理闭环：五步法

```
战略洞察 → 战略制定 → 战略展开（解码） → 战略执行与监控 → 战略评估与迭代
   ↑                                                              │
   └──────────────────── 反馈与修正 ──────────────────────────────┘
```

### 3.1 战略洞察

回答"机会在哪里、威胁是什么"。核心是**看清价值转移的方向**：利润正在从产业链的哪一环转移到哪一环？客户的决策标准正在怎么变？技术拐点是否临近？

洞察的产出不是资料汇编，而是**3–5 条可证伪的判断**，例如"未来三年，国内工业软件的增长将从新建项目转向存量替换，替换决策的第一标准是迁移成本而非功能数量"。判断必须带数据、带时间、带概率。

### 3.2 战略制定

在洞察基础上做选择：选客户、选战场、选打法、选节奏。产出一页纸的战略主张（strategy statement）：

> 为【哪类客户】提供【什么独特价值】，通过【什么能力/模式】实现，在【多长时间】内取得【什么可衡量的结果】，并且【明确放弃什么】。

"明确放弃什么"是这一页里最重要的一句。没有放弃，就没有战略。

### 3.3 战略展开（解码）

把战略主张拆成：战略主题 → 关键任务 → 衡量指标 → 重点工作 → 责任人与里程碑 → 预算。详见 `05_战略解码与执行闭环.md`。

### 3.4 战略执行与监控

靠三套机制：经营分析会（月度/季度看经营）、战略专题会（看关键任务进展）、资源调配机制（人、钱、授权随战略走）。监控的对象是**领先指标**，不是年底才算得出来的财务结果。

### 3.5 战略评估与迭代

半年一次战略复盘、一年一次战略刷新。评估三个问题：假设还成立吗？关键任务做成了吗？资源该重新分配吗？

## 4. DSTE：从战略到执行

DSTE（Develop Strategy To Execute）是华为在实践中成型的一套战略管理流程，把"规划—解码—执行—评估"固化为年度节拍。它的核心不是工具，而是**两个循环 + 一套会议体系**。

### 4.1 双循环：SP 与 BP

| | SP（Strategic Plan） | BP（Business Plan） |
|---|---|---|
| 周期 | 滚动 3–5 年 | 年度 |
| 频率 | 每年刷新一次 | 每年制定、每季滚动 |
| 内容 | 市场洞察、战略意图、业务设计、关键任务 | 经营目标、预算、组织与人力、考核方案 |
| 输出 | 战略规划书 | 年度经营计划 + 预算 + 组织 KPI |
| 决策场合 | 战略务虚会 / 董事会 | 经营班子会 / 预算评审会 |

SP 管"方向大致正确"，BP 管"当年打得赢"。SP 不刷新，BP 就会在错误的战场上越做越精细。

### 4.2 五个动作

1. **战略洞察**：五看（见下节）+ 差距分析；
2. **战略制定**：战略意图、创新焦点、业务设计；
3. **战略展开**：战略解码，形成组织 KPI 与重点工作；
4. **战略执行与监控**：经营分析会 + 战略专题会 + 滚动预测；
5. **战略评估**：半年复盘、年度述职、战略与预算的联动调整。

### 4.3 年度节拍（示例）

| 月份 | 动作 | 责任 |
|---|---|---|
| 4–6 月 | 市场洞察、客户与竞争调研 | 战略部 + 市场部 |
| 7–8 月 | SP 初稿、业务设计研讨 | 各 BU |
| 9 月 | 战略务虚会、SP 评审与定稿 | 经营班子 |
| 10–11 月 | 战略解码工作坊、组织 KPI 与重点工作 | 战略部 + HR |
| 11–12 月 | BP 与预算编制、PBC 签订 | 财务 + HR |
| 次年 1 月起 | 月度经营分析会、季度战略专题会 | 各级经营者 |

## 5. 五看三定

"五看三定"是战略洞察与制定的口语化框架，便于在工作坊中快速拉齐认知。

### 5.1 五看

| 看什么 | 关键问题 | 常用工具 |
|---|---|---|
| 看行业/趋势 | 行业处于什么阶段？技术拐点在哪？政策与资本流向哪里？ | PEST、产业生命周期、技术成熟度曲线 |
| 看市场/客户 | 客户是谁？需求如何分层？决策链与付费意愿怎样？ | 客户细分、客户旅程、JTBD、KANO |
| 看竞争 | 对手的战略意图、优势来源、下一步动作？ | 五力模型、战略群组、竞争雷达图 |
| 看自己 | 我们的真实能力与短板？哪些是可持续的？ | 价值链、VRIO、能力成熟度评估 |
| 看机会 | 哪些机会窗口正在打开？多大、多久、多难？ | 市场地图、TAM/SAM/SOM、机会评估矩阵 |

### 5.2 三定

1. **定战略控制点**——我们靠什么让优势难以被复制？常见控制点：品牌、专利与标准、客户转换成本、网络效应、规模成本、数据资产、渠道独占、生态位。
2. **定目标**——3–5 年目标 + 年度里程碑，必须可衡量（收入、份额、利润、客户数、能力指标）。
3. **定策略**——达成目标的路径选择：自建 / 合作 / 并购；先打哪个客户群；用什么节奏推进。

> 检验标准：三定写完后，如果一个竞争对手看到，他能立刻复制，说明控制点不成立。

## 6. 战略洞察的工具箱

| 工具 | 用途 | 输出 |
|---|---|---|
| PEST / PESTEL | 宏观环境扫描 | 机会与威胁清单 |
| 波特五力 | 行业吸引力与利润池 | 五力评分 + 利润池迁移判断 |
| 价值链 | 定位与外包决策 | 价值活动与利润分布图 |
| 产业生命周期 | 判断竞争主题 | 阶段判断 + 策略取向 |
| 战略群组图 | 竞争格局可视化 | 群组划分与移动路径 |
| 客户旅程 / JTBD | 需求洞察 | 痛点清单与机会点 |
| TAM/SAM/SOM | 市场空间测算 | 三层市场漏斗 |
| 机会评估矩阵 | 优先级排序 | 吸引力 × 能力 四象限 |
| 情景规划 | 应对不确定性 | 2–3 套情景与触发信号 |

## 7. 战略规划文档的标准结构（15 章）

1. 执行摘要（一页纸，结论先行）
2. 战略背景与规划假设
3. 宏观环境分析（PEST）
4. 行业与市场分析（规模、增速、结构、利润池）
5. 客户分析（细分、需求、决策链）
6. 竞争分析（对手、五力、战略群组）
7. 自身评估（能力、资源、差距）
8. 战略意图（愿景、使命、3–5 年目标）
9. 战略选择（业务组合、目标市场、价值主张）
10. 增长路径（内生 / 并购 / 合作，分年度里程碑）
11. 能力建设（组织、人才、技术、数字化）
12. 关键任务与重点工作
13. 财务预测与资源需求
14. 风险与应对（含退出条件）
15. 实施路线图与治理机制

## 8. 战略规划失败的十个典型原因

1. **没有洞察，只有口号**：目标定得很高，但对客户与竞争一无所知。
2. **不做取舍**：所有业务都要增长，所有客户都要服务，资源被摊薄。
3. **假设不写下来**：无法验证、无法复盘，错了也不知道错在哪。
4. **规划与预算两张皮**：战略说要投新业务，预算却按去年基数分配。
5. **规划与考核两张皮**：考核只看短期收入，没人对战略任务负责。
6. **没有领先指标**：等到财务报表出问题，已经晚了两个季度。
7. **解码不到位**：战略停在高层，中层不知道自己要做什么。
8. **一次规划管五年**：环境变了不刷新，用旧地图找新大陆。
9. **战略部独舞**：业务负责人不参与，规划变成文秘工作。
10. **没有退出机制**：投错了不认，继续加注。

## 9. 一页纸战略速查卡

```
【客户】我们为谁创造价值？（细分到可画像）
【价值】我们提供什么他们愿意付钱的独特价值？
【能力】我们凭什么持续做到？（战略控制点）
【取舍】我们明确不做什么？
【目标】3 年后的三个数字是什么？
【路径】分几步走？每年里程碑是什么？
【验证】哪三个领先指标能提前告诉我们走对了/走错了？
```
