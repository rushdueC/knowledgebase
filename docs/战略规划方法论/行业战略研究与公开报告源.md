# 行业战略研究与公开报告的使用方法

> 适用：行业研究、进入策略、投资尽调、战略规划的前置研究
> 关键词：行业分析、五力模型、价值链、产业生命周期、TAM/SAM/SOM、行业报告

## 1. 行业研究的五层框架

一份能支撑决策的行业研究，必须回答五个层次的问题，从外到内递进：

```
第 1 层  宏观环境     政策、技术、人口、资本、全球化
第 2 层  行业格局     规模、增速、集中度、利润池、生命周期
第 3 层  价值链       谁在赚钱、利润往哪转移、议价能力
第 4 层  竞争与标杆   对手的战略、能力、动作；标杆的成功要素
第 5 层  机会与切入   市场空间测算、进入路径、风险
```

多数"行业报告"只做到第 2 层（规模与增速），而战略决策需要第 3–5 层。读报告时要有意识地问：这份报告回答了哪几层？

## 2. 核心工具

### 2.1 PEST / PESTEL

| 维度 | 关注点 | 数据来源 |
|---|---|---|
| 政治（P） | 产业政策、监管、补贴、贸易摩擦 | 政府文件、部委规划 |
| 经济（E） | 增速、利率、汇率、通胀、消费力 | 统计局、央行 |
| 社会（S） | 人口结构、城镇化、消费习惯 | 人口普查、调研 |
| 技术（T） | 技术路线、成熟度、专利 | 专利库、技术路线图 |
| 环境（E） | 双碳、环保约束 | 生态环境部 |
| 法律（L） | 准入、合规、数据安全 | 法规库 |

### 2.2 波特五力

| 力量 | 判断问题 | 关键指标 |
|---|---|---|
| 现有竞争 | 对手数量、差异化、退出壁垒 | CR4/CR8、价格战频率 |
| 新进入者 | 资本门槛、牌照、渠道 | 近年新进入者数量 |
| 替代品 | 替代技术的性价比 | 替代品渗透率曲线 |
| 供应商 | 集中度、转换成本 | 前五大供应商占比 |
| 购买者 | 集中度、议价能力、信息透明 | 大客户收入占比 |

五力的价值不在打分，而在**判断利润池的位置与迁移方向**。

### 2.3 价值链

把行业拆成活动序列，逐段看：收入规模、毛利率、集中度、壁垒。

```
研发设计 → 原材料 → 零部件 → 整机制造 → 分销 → 零售 → 服务/运维 → 回收
```

典型发现：利润往往不在规模最大的环节，而在**壁垒最高的环节**（专利、标准、品牌、数据、渠道）。

### 2.4 产业生命周期

| 阶段 | 特征 | 战略主题 |
|---|---|---|
| 导入期 | 技术路线未定、玩家少、亏损 | 卡位、标准、试点 |
| 成长期 | 高速增长、玩家涌入、价格下降 | 抢份额、建产能、铺渠道 |
| 成熟期 | 增速放缓、集中度提升、价格战 | 效率、并购、差异化 |
| 衰退期 | 需求萎缩、产能出清 | 收缩、转型、收割 |

### 2.5 战略群组图

用两个关键维度（如"价格定位"×"渠道覆盖"）把对手画在二维图上，观察：
- 哪些群组拥挤（竞争激烈）；
- 哪些空白区存在（可能是机会，也可能是伪需求）；
- 群组间的移动路径（谁在往哪走）。

### 2.6 市场空间测算：TAM / SAM / SOM

| 层级 | 定义 | 算法 |
|---|---|---|
| TAM | 总可及市场 | 总需求 × 单价（自上而下）或 客户数 × 渗透率 × 客单价（自下而上） |
| SAM | 可服务市场 | TAM 中符合地理、合规、产品能力的部分 |
| SOM | 可获得市场 | SAM 中 3 年内凭竞争力能拿到的份额 |

**要点**：自上而下算完必须用自下而上校验，两者差 3 倍以上说明假设有问题。所有测算必须写明假设与来源年份。

### 2.7 关键成功因素（KSF）

问：在这个行业里，做到前 20% 的企业，共同做对了哪 3–5 件事？

常见 KSF：成本控制、渠道密度、品牌、技术迭代速度、供应链韧性、合规能力、客户关系、数据资产。

## 3. 报告解构法：读一份行业报告的八个动作

1. **看封面与目录**：判断它回答哪几层问题，是"数据型"还是"观点型"。
2. **看发布机构**：政府智库（权威但滞后）、咨询公司（框架好但样本小）、券商（数据全但立场偏）、商业报告平台（覆盖广但深度浅）。
3. **看口径**：同一个"市场规模"，统计口径可能差 2–3 倍（出货量 vs 销售额、全球 vs 中国、含服务 vs 不含）。
4. **看假设**：增速预测基于什么前提？前提变了结论还成立吗？
5. **看图表来源**：图表下方的小字往往暴露数据是一手调研还是二手引用。
6. **看结论的边界**：报告说"预计 2030 年达到 X"，是在什么情景下？
7. **交叉验证**：用两个以上独立来源验证同一个关键数字。
8. **提炼可行动结论**：把"行业增长 15%"翻译成"我们的哪个产品线、在哪个区域、能拿多少"。

### 4.4 商业报告平台

艾瑞、易观、头豹、前瞻、中商——覆盖广、更新快，但需注意口径与利益相关方。适合做"快速建立认知"，不适合做"唯一依据"。

## 5. 行业战略报告的标准骨架

```
1. 摘要（3 条结论 + 3 个建议）
2. 研究范围与方法（口径、数据来源、假设）
3. 宏观环境（PEST）
4. 行业规模与增长（历史 5 年 + 预测 5 年，含敏感性）
5. 行业结构（集中度、价值链、利润池）
6. 竞争格局（五力、战略群组、主要玩家画像）
7. 客户与需求（细分、决策链、付费意愿）
8. 技术与产品趋势（路线图、拐点）
9. 政策与监管（现状 + 趋势 + 影响）
10. 机会识别（TAM/SAM/SOM、机会矩阵）
11. 进入策略（自建/合作/并购、节奏、资源需求）
12. 风险与应对（含退出条件）
13. 附录（数据表、访谈纪要、参考文献）
```

## 6. 写作规范

- **结论先行**：每章开头一句话结论，再展开论证。
- **数据溯源**：每个关键数字标注"来源 + 年份 + 口径"。
- **图表三件套**：标题说结论（不是"图 1 市场规模"），坐标轴标单位，来源标在下方。
- **区分事实与判断**：事实用数据，判断用"我们估计/假设"，不要混写。
- **给可执行建议**：不要停在"行业前景广阔"，要写"建议在 2027 年前以 XX 方式进入 XX 细分"。

## 7. 十个常见错误

1. 用一份报告的结论当事实，不做交叉验证。
2. 市场规模口径混乱（全球/中国、金额/数量、含/不含服务）。
3. 只算 TAM，不算 SAM/SOM，得出"市场很大所以我们能做大"。
4. 把行业增速等同于企业增速。
5. 忽视集中度与进入壁垒，低估竞争强度。
6. 用平均数掩盖结构（平均毛利 30%，但头部 50%、尾部 5%）。
7. 预测线性外推，忽视拐点与政策变化。
8. 只研究头部对手，忽视跨界进入者。
9. 结论没有时间与情景限定。
10. 报告写完没有"所以我们要做什么"。

## 8. 一个快速上手的工作流（5 天）

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | 定范围与口径，列出 10 个关键问题 | 研究提纲 |
| D2 | 收集 5–8 份权威报告 + 官方数据 | 资料库 |
| D3 | 做规模测算与结构分析（价值链、集中度） | 数据表 + 图 |
| D4 | 竞争与客户分析，访谈 3–5 位从业者 | 竞争图谱 + 洞察 |
| D5 | 形成结论与建议，写 10 页正文 | 行业研究简报 |
